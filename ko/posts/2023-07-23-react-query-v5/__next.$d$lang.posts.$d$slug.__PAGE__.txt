<li>
<p>Removed refetchPage in favor of maxPages</p>
<ul>
<li>v4에서 refetchPage를 제공했지만, 전체페이지 로딩(필터)한다면 infinite queries에 용도와 맞지 않는 이슈가 있어서 refechPage는 삭제처리 하였음</li>
<li>단, 최대 페이지 수를 제한하는 기능인 maxPages 옵션이 추가되었습니다.</li>
</ul>
</li>
<li>
<p>Window focus refetching no longer listens to the focus event</p>
<ul>
<li>visibilitychange 이벤트를 지원하는 브라우저만 지원하기로 결정했기 때문에, 이전에 사용하던 focus 이벤트는 listen 하지 않음</li>
</ul>
</li>
<li>
<p>No longer using unstable_batchedUpdates as the batching function in React and React Native</p>
<ul>
<li>react, react-native에서 배치 실행 시 사용되는 unstable_batchedUpdates를 더 이상 사용하지 않음.</li>
</ul>
