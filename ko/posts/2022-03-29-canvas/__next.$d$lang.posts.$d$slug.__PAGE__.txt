<ul>
<li>Canvas API는 <a href="https://developer.mozilla.org/ko/docs/Web/JavaScript">JavaScript</a>와 <a href="https://developer.mozilla.org/ko/docs/Web/HTML">HTML</a> <a href="https://developer.mozilla.org/ko/docs/Web/HTML/Element/canvas">CANVAS</a> 엘리먼트를 통해 그래픽을 그리기위한 수단을 제공합니다. 무엇보다도 애니메이션, 게임 그래픽, 데이터 시각화, 사진 조작 및 실시간 비디오 처리를 위해 사용됩니다.</li>

<h2 id="라이브러리">라이브러리<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#라이브러리"><span class="icon icon-link"></span></a></h2>
<ul>
<li><a href="https://www.createjs.com/easeljs">EaselJS</a>는 게임, 생성 예술 및 기타 고도의 그래픽 경험을 쉽게 생성할 수 있게 해주는 오픈소스 캔버스 라이브러리입니다.</li>
<li><a href="http://fabricjs.com/">Fabric.js</a>는 SVG 파싱 기능을 갖춘 오픈소스 캔버스 라이브러리입니다.</li>
<li><a href="https://www.patrick-wied.at/static/heatmapjs/">heatmap.js</a>는 캔버스 기반 데이터 열지도를 생성하기위한 오픈소스 라이브러리입니다.</li>
<li><a href="https://thejit.org/">JavaScript InfoVis Toolkit</a>은 인터렉티브한 데이터 시각화를 생성합니다.</li>
<li><a href="https://konvajs.github.io/">Konva.js</a>는 데스크탑 및 모바일 애플리케이션을 위한 2D 캔버스 라이브러리입니다.</li>
<li><a href="https://p5js.org/">p5.js</a>는 예술가, 디자이너, 교육자 및 입문자를 위한 캔버스 그리기 기능의 모든 세트를 포함하고 있습니다.</li>
<li><a href="http://paperjs.org/">Paper.js</a>는 HTML5 Canvas 위에서 실행되는 오픈소스 벡터 그래픽 스크립팅 프레임워크입니다.</li>
<li><a href="https://phaser.io/">Phaser</a>는 Canvas 및 WebGL 기반의 브라우저 게임을 위한 빠르고, 자유롭고, 재미있는 오픈소스 프레임워크입니다.</li>
<li><a href="https://processingjs.org/">Processing.js</a>는 Processing 시각화 언어의 포트입니다.</li>
<li><a href="https://ptsjs.org/">Pts.js</a>는 canvas 및 SVG를 사용한 창의적인 코딩 및 시각화를 위한 라이브러리입니다.</li>
<li><a href="https://github.com/jeremyckahn/rekapi">Rekapi</a>는 Canvas를 위한 애니메이션 키 프레임 API입니다.</li>
<li><a href="https://scrawl.rikweb.org.uk/">Scrawl-canvas</a>는 2D 캔버스 엘리먼트를 생성하고 조작하기위한 오픈소스 JavaScript 라이브러리입니다.</li>
<li><a href="https://zimjs.com/">ZIM</a> 프레임워크는 canvas에서의 창의적인 코딩을 위한 편의성, 컴포넌트 및 컨트롤을 제공하는 프레임워크입니다. 접근성 및 다채로운 튜토리얼을 포함합니다.</li>
</ul>

<h3 id="사각형-그리기">사각형 그리기<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#사각형-그리기"><span class="icon icon-link"></span></a></h3>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/fillRect">fillRect(x, y, width, height) (en-US)</a></p>
<p>색칠된 직사각형을 그립니다.</p>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/strokeRect">strokeRect(x, y, width, height) (en-US)</a></p>
<p>직사각형 윤곽선을 그립니다.</p>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/clearRect">clearRect(x, y, width, height) (en-US)</a></p>
<p>특정 부분을 지우는 직사각형이며, 이 지워진 부분은 완전히 투명해집니다.</p>
<pre><code>const cx = x;
const cy = y;
const cw = w;
const ch = h;

ctx.save();
ctx.clearRect(cx, cy, cw, ch); // 캔버스 지우기

if (props &#x26;&#x26; props.outline === true) {
  ctx.strokeStyle = props.color; // 외곽선 색상
  ctx.strokeRect(cx, cy, cw, ch); // 사각형 그리기(외곽선)
} else {
  ctx.fillStyle = props.color; // 채우기 색상
  ctx.fillRect(cx, cy, cw, ch); // 사각형 그리기(채우기)
}

ctx.restore();

</code></pre>

<h3 id="경로-그리기">경로 그리기<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#경로-그리기"><span class="icon icon-link"></span></a></h3>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/beginPath">beginPath() (en-US)</a></p>
<p>새로운 경로를 만듭니다. 경로가 생성됬다면, 이후 그리기 명령들은 경로를 구성하고 만드는데 사용하게 됩니다.</p>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/closePath">closePath() (en-US)</a></p>
<p>현재 하위 경로의 시작 부분과 연결된 직선을 추가합니다.</p>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/stroke">stroke() (en-US)</a></p>
<p>윤곽선을 이용하여 도형을 그립니다.</p>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/fill">fill() (en-US)</a></p>
<p>경로의 내부를 채워서 내부가 채워진 도형을 그립니다.</p>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/moveTo">moveTo() (en-US)</a></p>
<p>새로운 좌표인 x,y 좌표로 이동시킵니다.</p>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/lineTo">lineTo() (en-US)</a></p>
<p>이동 시킨 좌표값을 바탕으로 라인을 추가시킵니다.</p>
<p>Path 메소드 (<a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D#paths">Path methods</a>)</p>
<p>물체를 구성할 때 필요한 여러 경로를 설정하는데 사용하는 함수입니다.</p>

<h3 id="원-그리기">원 그리기<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#원-그리기"><span class="icon icon-link"></span></a></h3>
<p>호 그리기</p>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/arc">arc(x, y, radius, startAngle, endAngle, anticlockwise) (en-US)</a></p>
<p><em>(x, y)</em> 위치에 원점을 두면서, 반지름 r을 가지고,  <em>startAngle</em> 에서 시작하여 <em>endAngle</em> 에서 끝나며 주어진 <em>anticlockwise</em> 방향으로 향하는 (기본값은 시계방향 회전) 호를 그리게 됩니다.</p>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/arcTo">arcTo(x1, y1, x2, y2, radius) (en-US)</a></p>
<p>주어진 제어점들과 반지름으로 호를 그리고,  이전 점과 직선으로 연결합니다.</p>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/ellipse">ellipse(x, y, radiusX, radiusY, rotation, startAngle, endAngle [, counterclockwise]) (en-US)</a></p>

<h2 id="텍스트-그리기">텍스트 그리기<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#텍스트-그리기"><span class="icon icon-link"></span></a></h2>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/fillText">fillText(text, x, y [, maxWidth]) (en-US)</a></p>
<p>주어진 (x, y) 위치에 주어진 텍스트를 채웁니다. 최대 폭(width)은 옵션 값 입니다.</p>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/strokeText">strokeText(text, x, y [, maxWidth]) (en-US)</a></p>
<p>주어진 (x, y) 위치에 주어진 텍스트를 칠(stroke)합니다. 최대 폭(width)은 옵션 값 입니다.</p>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/font">font = value (en-US)</a></p>
<p>텍스트를 그릴 때 사용되는 현재 텍스트 스타일. 이 문자열은 <a href="https://developer.mozilla.org/en-US/docs/Web/CSS">CSS</a> <a href="https://developer.mozilla.org/ko/docs/Web/CSS/font">font</a> 프로퍼티와 동일한구문을 사용합니다. 기본값으로 sans-serif의 10px가 설정되어 있습니다.</p>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/textAlign">textAlign = value (en-US)</a></p>
<p>텍스트 정렬 설정. 사용가능한 값: start, end, left, right, center. 기본 값은 start 입니다.</p>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/textBaseline">textBaseline = value (en-US)</a></p>
<p>베이스라인 정렬 설정. 사용가능한 값: top, hanging, middle, alphabetic, ideographic, bottom. 기본 값은 alphabetic 입니다</p>
<ul>
<li>설명
<ul>
<li>top: 베이스라인이 문자열의 위쪽에 온다.</li>
<li>middle: 베이스라인이 문자열의 중앙에 온다.</li>
<li>bottom: 베이스라인이 문자열의 아래쪽에 온다.</li>
<li>alphabetic: 알파벳의 baseline에 맞춘다. 이 값이 디폴트이다.</li>
<li>hanging: 문자의 위쪽에 맞춘다. 인도의 언어가 이 방식을 사용한다.</li>
<li>ideographic: 한자나 일본어처럼 사각형 문자가 이 방식을 사용한다. 알파벳보다는 베이스라인이 약간 더 아래쪽에 위치한다.</li>
</ul>
</li>
</ul>

<h2 id="이미지그리기">이미지그리기<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#이미지그리기"><span class="icon icon-link"></span></a></h2>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/drawImage">drawImage(image, x, y) (en-US)</a></p>
<ul>
<li>이미지를 원래 크기로 삽입
<ul>
<li>image : 이미지(DOM image) 또는 Canvas 개체 또는 video 요소</li>
<li>x: 이미지 출력할 x 좌표</li>
<li>y: 이미지 출력할 y 좌표</li>
</ul>
</li>
</ul>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/drawImage">drawImage(image, x, y, width, height) (en-US)</a></p>
<ul>
<li>이미지를 지정한 크기로 삽입
<ul>
<li>width: 이미지 너비</li>
<li>height: 이미지 높이</li>
</ul>
</li>
</ul>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/drawImage">drawImage(image, sx, sy, sWidth, sHeight, dx, dy, dWidth, dHeight) (en-US)</a></p>
<ul>
<li>이미지의 일부분을 잘라내어 삽입
<ul>
<li>sx : 이미지 출력할 x 좌표</li>
<li>sy : 이미지 출력할 y 좌표</li>
<li>sWidth : [옵션] 이미지 width /원본(source) 잘라낼 영역(clipping rectangle)</li>
<li>sHeight : [옵션] 이미지 Height /원본(source) 잘라낼 영역(clipping rectangle)</li>
<li>dx : [옵션] 만약 잘라내었다면, 대상 이미지의 X좌표</li>
<li>dy : [옵션] 만약 잘라내었다면, 대상 이미지의 Y좌표</li>
<li>dWidth : [옵션] 만약 잘라내었다면, 대상 이미지의 width</li>
<li>dHeight : [옵션] 만약 잘라내었다면, 대상 이미지의 Height</li>
</ul>
</li>
</ul>
<h2 id="애니메이션">애니메이션<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#애니메이션"><span class="icon icon-link"></span></a></h2>
<p>애니메이션 단계</p>
<ol>
<li>캔버스를 비웁니다.(ctx.clearRect) 그리려는 도형이 (배경 이미지를 만들 때처럼) 캔버스를 가득 채우는 것이 아니라면, 이전에 그려진 모든 도형을 지울 필요가 있습니다. 가장 쉬운 방법은 clearRect() 메소드를 사용하는 것입니다.</li>
<li>캔버스 상태를 저장합니다.(ctx.save) 캔버스 상태에 영향을 주는 (스타일 변경, 모양 변형 등의) 설정값을 바꾸려고 하고, 바뀐 값을 각 장면마다 사용하려고 한다면, 원래 상태를 저장할 필요가 있습니다.</li>
<li>애니메이션할 도형을 그립니다.(ctx.fill, stroke~~) 실제 장면을 그리는 단계입니다.</li>
<li>캔버스 상태를 복원합니다.(ctx.restore) 새로운 장면을 그리기 전에 저장된 상태를 복원합니다.</li>
</ol>
<p>정해진 시간마다 특정 함수 호출</p>
<ul>
<li>setInterval(function, delay)
<ul>
<li>delay 밀리세컨드(1,000분의 1초)마다 function 함수 반복 실행을 시작합니다.</li>
</ul>
</li>
<li>setTimeout(function, delay)
<ul>
<li>delay 밀리세컨드(1,000분의 1초) 경과후, function 함수를 실행합니다.</li>
</ul>
</li>
<li>requestAnimationFrame(function)
<ul>
<li>디스플레이 주사율과 일치하게 function 함수를 실행합니다.</li>
</ul>
</li>
</ul>
