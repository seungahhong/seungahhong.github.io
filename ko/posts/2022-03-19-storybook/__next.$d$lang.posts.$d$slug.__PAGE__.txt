b:Teb16,<h2 id="도입목적">도입목적<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#도입목적"><span class="icon icon-link"></span></a></h2>
<ul>
<li>기획, 디자인이 병렬로 진행중인 사항에서 계속적으로 스펙이 변경됨을 반영해서 기획자, 디자이너에 공유를 목적으로 합니다.</li>
<li>백엔드와도 병렬로 진행 시 로직(container), 화면(presentation) 분리해서 진행해야함으로 그것을 검증하기 위해서 storybook 단위의 컴포넌트 개발을 진행합니다.</li>
<li>추후에 화면단위 테스트 진행 시 storybook을 적극 활용합니다.</li>
<li>그외
<ul>
<li>접근성에 대한 부분도 같이 고민하면서 화면단위 컴포넌트를 개발을 진행합니다.</li>
</ul>
</li>
</ul>

<h2 id="addon-knobs-적용">addon-knobs 적용<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#addon-knobs-적용"><span class="icon icon-link"></span></a></h2>
<ul>
<li>@storybook/addon-knobs
<ul>
<li>다양한 컴포넌트와의 상호작용을 할 수 있도록 도와주는 addon 입니다.</li>
</ul>
</li>
<li>Knobs 컨트롤 종류
<ul>
<li>text: 텍스트를 입력 할 수 있습니다.</li>
<li>boolean: true/false 값을 체크박스로 설정 할 수 있습니다.</li>
<li>number: 숫자를 입력 할 수 있습니다. 1~10과 같이 간격을 설정 할 수도 있습니다.</li>
<li>color: 컬러 팔레트를 통해 색상을 설정 할 수 있습니다.</li>
<li>object: JSON 형태로 객체 또는 배열을 설정 할 수 있습니다.</li>
<li>select: 셀렉트 박스를 통하여 여러가지 옵션 중에 하나를 선택 할 수 있습니다.</li>
<li>radios: Radio 버튼을 통하여 여러가지 옵션 중에 하나를 선택 할 수 있습니다.</li>
<li>date: 날짜를 선택 할 수 있습니다.
<img src="/blog-assets/2022/03/assets/19/Untitled.png" alt="Untitled"></li>
</ul>
</li>
</ul>
