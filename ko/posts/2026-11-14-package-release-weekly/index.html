이번 주 패키지 릴리스 정리 — 2026-11-14

홍홍승아·2026.11.14·22분

✍️ 한 줄 요약

Node.js가 26·24·22 세 LTS 라인에 HTTP/2·TLS 관련 High 등급 CVE 여러 건을 고친 보안 릴리스를 냈고, Grafana(CVE 6건)·Gradle(Critical 등급 포함 보안 권고 3건)·Podman(CVE 3건)도 보안 수정을 냈습니다. Rust 1.100.0은 never 타입(!)과 커스텀 할당자(allocator) API를 안정화했고, Kyverno 1.20.0은 변경 이력상 레거시 kyverno.io 정책 엔진을 제거하는 커밋이 들어 있어 올리기 전에 꼭 확인해야 합니다.

이번 주 한눈에 보기

기간은 2026-11-07 ~ 2026-11-14(KST)이며, 추적 중인 87개 패키지 가운데 35개의 변경점을 확인했습니다. 지난주 글에서 이미 다룬 버전(Angular 22.2.5, Tailwind CSS 4.3.5, Nx 24.0.5, Istio 1.31.4·1.30.8)은 기간 경계에 걸쳐 있어도 다시 넣지 않았습니다.

이번 주도 GitHub 릴리스 페이지를 읽을 수 없어, CHANGELOG나 저장소 안 릴리스 노트가 있는 패키지는 그 파일을, 없는 패키지는 새 태그까지의 변경 이력(커밋 제목)을 읽고 정리했습니다. 변경 이력으로 정리한 패키지는 릴리스 공지를 없음으로 표시했고, breaking change(기존 코드를 고쳐야 하는 변경) 여부는 확인하지 못했습니다.

Node.js v26.13.1 · v24.22.3 · v22.23.5

자바스크립트 런타임입니다.

무엇이 바뀌었나 — 세 라인 모두 보안 릴리스입니다. HTTP/2 스트림을 정리할 때 헤더·버퍼를 놓치거나 nghttp2가 버린 스트림을 감지하지 못하던 문제, 빈 쓰기로 HTTP 파서가 중첩 실행되던 문제, TLS 세션 재개·재협상으로 SNI가 바뀌거나 mTLS에서 재개가 허용되던 문제, 원격에서 TLS 서버를 죽일 수 있던 문제(26·24 라인)가 High 등급으로 고쳐졌습니다. Medium·Low 등급으로는 ALTSVC 버퍼 오버플로, 잘못된 프록시 URL 오류 메시지에 자격 증명이 노출되던 문제, 권한 모델에서 재귀 fs.watch가 거부된 하위 경로를 드러내던 문제 등이 포함됩니다. 26.13.1은 'Lithium' LTS 라인으로 표기돼 있습니다.

업그레이드할 때 확인할 점 — HTTP/2나 TLS 서버를 직접 운영한다면 바로 올리는 것이 좋습니다. 같은 패치 버전 안의 보안 수정이라 API 변경은 적혀 있지 않습니다.

릴리스 공지: CHANGELOG_V26

astro 7.4.12

JavaScript 웹 프레임워크입니다.

무엇이 바뀌었나 — 7.4.11은 security.allowedDomains가 X-Forwarded-Proto·X-Forwarded-Host·X-Forwarded-Port를 따로 검사하던 것을 한 항목 안에서 함께 검사하도록 바꾸고, ftp·ws 같은 HTTP(S)가 아닌 프로토콜 값을 받아들이던 문제를 고쳤습니다. astro build가 Vite build.license 파일을 지우던 문제, 잘못된 퍼센트 인코딩 경로가 500 대신 400을 돌려주도록 한 수정도 있습니다. 7.4.9는 strictDynamic CSP에서 번들 스크립트가 막히던 문제를, 7.4.12는 빌드 중 콘텐츠 컬렉션 메모리 사용을 줄였습니다.

업그레이드할 때 확인할 점 — 프록시 뒤에서 security.allowedDomains를 쓴다면, 포트·프로토콜이 항목에 명시돼 있지 않으면 이제 전달 헤더 값이 적용되지 않을 수 있으니 설정을 확인하세요.

Grafana 13.3.1 · 13.2.6 · 13.1.10 · 13.0.13

무엇이 바뀌었나 — never 타입(!)이 안정화되고 Infallible이 !의 별칭이 됐으며, 모든 에디션에서 never 타입 fallback이 !로 바뀌었습니다. std::alloc::Allocator와 Box::new_in·Vec::new_in 등 커스텀 할당자 API가 안정화됐고, bool::toggle, Box::map·Arc::map, core::mem::DropGuard도 쓸 수 있습니다. extern "custom"과 -Cprofile-sample-use가 안정화되고 wasm32-wasip3가 Tier 2가 됐습니다.

업그레이드할 때 확인할 점 — 호환성 노트에 if let 클로저 캡처 변경으로 새 오류가 날 수 있다는 점, box 패턴 문법 제거, never 타입 fallback 변경이 적혀 있으니 빌드를 먼저 돌려 보세요.

Vue Router 5.5.1 · 5.5.0 · 4.6.5

Vue.js 라우팅 라이브러리입니다.

무엇이 바뀌었나 — 5.5.0은 스크롤 위치를 history.state 대신 sessionStorage에 저장하고(실패하면 메모리에 보관), 스크롤 복원 트리거를 설정할 수 있게 했으며, .* 반복 파라미터의 지수적 백트래킹을 막았습니다. unplugin의 definePage가 webpack·rspack에서 동작하고 props: true일 때 defineProps()에 라우트 파라미터 타입이 붙습니다. 5.5.1은 vue-router/experimental 사용자에게 breaking change가 있어, 매처가 일치하지 않으면 throw 대신 null을 반환하고 MatchMiss가 더 이상 Error를 상속하지 않습니다. 4.6.5 변경은 읽지 못했습니다.

업그레이드할 때 확인할 점 — 실험 라우터를 쓴다면 커스텀 매처와 instanceof Error·error.name 검사 코드를 고쳐야 합니다. 스크롤 위치 저장 위치가 바뀐 점도 확인하세요.
