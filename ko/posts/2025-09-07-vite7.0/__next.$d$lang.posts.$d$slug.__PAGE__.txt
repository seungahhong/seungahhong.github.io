<p>2025년 6월 24일, Vite 7.0이 공식 출시되었습니다. 이번 메이저 버전은 Node.js 지원 정책 변경, 브라우저 타겟 업데이트, Rolldown 통합 등 중요한 변경사항을 포함하고 있습니다. 주간 다운로드 수는 3,100만 건에 달하며, 지난 메이저 릴리즈 이후 1,400만 건이 증가했습니다.</p>

<h3 id="주요-변경사항">주요 변경사항<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#주요-변경사항"><span class="icon icon-link"></span></a></h3>
<h4 id="1-nodejs-지원-요구사항-상향">1. Node.js 지원 요구사항 상향<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#1-nodejs-지원-요구사항-상향"><span class="icon icon-link"></span></a></h4>
<p>Vite 7.0은 이제 <strong>Node.js 20.19+ 또는 22.12+</strong> 버전을 요구합니다.</p>
<p><strong>변경 이유:</strong></p>
<ul>
<li><code>require(esm)</code> 지원을 위해 플래그 없이 사용 가능한 Node.js 버전 필요</li>
<li>Vite를 ESM 전용으로 배포 가능</li>
<li>Node.js 18 지원 중단</li>
</ul>
<h4 id="2-브라우저-타겟-변경">2. 브라우저 타겟 변경<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#2-브라우저-타겟-변경"><span class="icon icon-link"></span></a></h4>
<p>기본 브라우저 타겟이 <code>'modules'</code>에서 <code>'baseline-widely-available'</code>로 변경되었습니다.</p>
<p><strong>최소 브라우저 버전 업데이트:</strong></p>






























<table><thead><tr><th>브라우저</th><th>Vite 6.0</th><th>Vite 7.0</th></tr></thead><tbody><tr><td>Chrome</td><td>87</td><td>107</td></tr><tr><td>Edge</td><td>88</td><td>107</td></tr><tr><td>Firefox</td><td>78</td><td>104</td></tr><tr><td>Safari</td><td>14.0</td><td>16.0</td></tr></tbody></table>
<p>이 변경으로 더 현대적인 JavaScript 기능을 활용할 수 있게 되어 번들 크기가 줄어들고 성능이 향상됩니다.</p>
<h4 id="3-environment-api-개선">3. Environment API 개선<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#3-environment-api-개선"><span class="icon icon-link"></span></a></h4>
<p>Vite 6에서 도입된 실험적 Environment API가 유지되었으며, 새로운 기능이 추가되었습니다.</p>
<p><strong>주요 추가사항:</strong></p>
<ul>
<li><code>buildApp</code> 훅: 환경 빌드 중 플러그인 간 조정을 위한 새로운 훅</li>
<li>더 나은 플러그인 호환성과 환경별 빌드 제어</li>
</ul>

<h3 id="마무리">마무리<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#마무리"><span class="icon icon-link"></span></a></h3>
<p>Vite 7.0은 성능, 현대성, 개발자 경험을 개선하는 중요한 업데이트입니다. Node.js 요구사항 변경과 일부 deprecated 기능 제거가 있지만, 전반적으로 Vite 6에서 부드러운 마이그레이션이 가능합니다.</p>
<p><strong>주요 체크리스트:</strong></p>
<ul>
<li>✅ Node.js 20.19+ 또는 22.12+ 업그레이드</li>
<li>✅ 브라우저 타겟 검토</li>
<li>✅ Deprecated 기능 제거</li>
<li>✅ Vitest 3.2+ 업데이트 (해당 시)</li>
<li>✅ Rolldown 실험적 기능 테스트 (선택사항)</li>
</ul>
