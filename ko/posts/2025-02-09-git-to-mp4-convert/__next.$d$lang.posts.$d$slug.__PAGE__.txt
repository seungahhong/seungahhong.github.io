c:T712c,<h2 id="개요">개요<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#개요"><span class="icon icon-link"></span></a></h2>
<p>리소스 중에 용량이 큰 gif 포멧을 효율적인 압축 방식을 제공하는 mp4 비디오 포멧으로 변경해서 리소스 수신 용량을 줄이고 로딩 속도를 개선하기 위해서 해당 기능을 서비스에 적용을 위한 성능개선 작업을 진행하였습니다.</p>
<h2 id="요구사항-분석">요구사항 분석<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#요구사항-분석"><span class="icon icon-link"></span></a></h2>
<ul>
<li>변환 형식
<ul>
<li>img > gif → video > mp4</li>
<li>동일한 파일명이 있는 mp4 파일이 있는 경우 gif 보다는 mp4 로딩되도록 처리</li>
</ul>
</li>
<li>placeholder 적용
<ul>
<li>dataset에서 저장된 이미지 너비, 높이값을 바탕으로 placeholder 높이값 지정</li>
</ul>
</li>
<li>사이즈 재 계산
<ul>
<li>브라우저 리사이즈 발생 시 너비/높이 사이즈를 재계산</li>
</ul>
</li>
<li>뷰포트 기준 mp4 로딩/재생/일시중지 작업
<ul>
<li>viewport 기준 영역에 도달했을 때 mp4 로딩 되도록 수정</li>
</ul>
</li>
<li>gif 동작과 동일한 기능 제공
<ul>
<li>autoplay, mute, loop, playinline</li>
</ul>
</li>
</ul>
