<h2 id="참고코드">참고코드<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#참고코드"><span class="icon icon-link"></span></a></h2>
<p>참고코드: <a href="https://github.com/seungahhong/states-todos">GitHub - seungahhong/states-todos</a></p>
<h2 id="jotai-개념-특장점-설명">Jotai 개념, 특장점 설명<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#jotai-개념-특장점-설명"><span class="icon icon-link"></span></a></h2>
<ul>
<li>상태관리 설명
요즘 상태관리에 대한 접근 방식을 3가지로 나눠서 볼 수 있을 것 같습니다.
<ul>
<li>Flux (Redux, Zustand)
<ul>
<li>일반적으로 사용하는 Flux 방식으로써, 저장소(store)/액션함수(action)/리듀서 등을 통해서 상태를 업데이트 하는 방식</li>
</ul>
</li>
<li>Proxy (Mobx, Valtio)
<ul>
<li>컴포넌트에 사용되는 일부 상태를 자동으로 감지해서 업데이트 하는 방식</li>
</ul>
</li>
<li>Atomic (Jotai, Recoil)
<ul>
<li>React에 사용되는 state와 비슷하게 리액트 트리 안에서 상태를 저장하고 관리하는 방식</li>
</ul>
</li>
</ul>
</li>
<li>Jotai 개념
<ul>
<li>주요개념
<ul>
<li>최소 API</li>
<li>TypeScript 내장</li>
<li>작은 번들 크기(3kb)</li>
<li>많은 추가 유틸리티 및 공식 통합</li>
<li>Next.js 및 React Native 지원</li>
<li>리액트에서만 사용가능</li>
</ul>
</li>
<li>소개
<ul>
<li>Jotai 일본어로 상태를 뜻하고, 같은 개발 그룹인 <a href="https://pmnd.rs/">Pmndrs</a>에서 만든 <a href="https://github.com/pmndrs/zustand">Zustand</a> 라는 상태 관리 라이브러리도 있는데 이는 독일어로 상태를 뜻합니다.</li>
<li>Context의 re-rendering 문제를 해결하기 위해 만들어진 React 특화 상태관리 라이브러리</li>
<li>리액트에서는 useContext, useState를 top-down 방식을 개선하기 위해서, Recoil과 비슷한게 atomic한 상태관리 방식으로 구성됨(bottom-up 방식)
<img src="/blog-assets/2022/06/images/14/Untitled.png" alt="Untitled"></li>
</ul>
</li>
</ul>
</li>
<li>Jotai 특장점
<ul>
<li>기본적으로 re-rendering 문제를 줄여주고,selectAtom,splitAtom 과 같은 re-rendering 을 줄이기 위한 유틸들도 지원한다.</li>
<li>보일러 플레이트 코드가 redux에 비하면 현저하게 줄어든다.</li>
<li>React 의 주요 feature일 Suspense(Concurrent mode)를 적용하는데에 적합하게 설계</li>
<li>Jotai 가 강조하는 두가지 특징
<ul>
<li>Primitive: 리액트 기본 state 함수인 useState 와 유사한 인터페이스</li>
<li>Flexible: atom들끼리 서로 결합 및 상태에 관여할 수 있고, 다른 라이브러리들과 원할한 결합을 지원(특히, redux와 상태관리 연동 가능)</li>
</ul>
</li>
</ul>
</li>
</ul>

<h2 id="개인의견">개인의견<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#개인의견"><span class="icon icon-link"></span></a></h2>
<ul>
<li>멀티 스토어를 통해서 상태관리를 지원이 필요하다면 충분히 사용해도 좋을 라이브러리 같다.</li>
<li>Jotai 자체에서 지원하는 라이브러리가 많아서 쉽게 사용이 가능할 것 같다.(단, 라이브러리 풀지원이 되는지 여부 확인)</li>
<li>recoil 상태관리보다는 문법 자체가 쉬워 보인다.
<ul>
<li>모든 단위를 atom으로 통일</li>
<li>unique key가 없는것도 편하게 느껴짐</li>
</ul>
</li>
<li>여러 회사에서 적용을 해본것으로 보아서 어느정도 안정성은 확보된 것 같습니다.(카카오스타일, 화해 등등)</li>
<li>리액트 트리기반의 소규모 프로젝트에 적용해볼만한 상태관리 툴인 것 같습니다.</li>
