f:T5ff1,<h3 id="개요">개요<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#개요"><span class="icon icon-link"></span></a></h3>
<p>나무를 흔들어 잔가지를 털어내듯 <strong>불필요한 코드를 제거</strong>하는 최적화 작업</p>
<ul>
<li>Webpack 4버전 이상을 사용하는 경우에는 ES6 모듈을 대상으로 기본적인 트리쉐이킹을 제공한다.(<code>import</code>, <code>export</code>를 사용하는 모듈)</li>
<li>Create React App을 통해 만든 React 애플리케이션도 Webpack을 사용하고 있기 때문에 트리쉐이킹이 가능하다.</li>
</ul>

<h3 id="tree-shaking-설정"><strong>Tree Shaking 설정</strong><a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#tree-shaking-설정"><span class="icon icon-link"></span></a></h3>
<p><a href="https://v4.webpack.js.org/guides/tree-shaking">webpack 공식 문서</a>를 확인해보면 tree shaking 설정을 위해 해 줘야 되는 행동은 4가지가 있습니다.</p>
<ul>
<li>ES6 모듈 포맷 사용 (ex, import / export)</li>
<li>commonjs로 컴파일되는 것 방지하기 (@babel/preset-env 설정 등을 이용)</li>
<li>package.json에 sideEffects 속성 사용</li>
<li>webpack production mode 사용</li>
</ul>
<h2 id="react-tree-shaking"><strong>React Tree Shaking</strong><a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#react-tree-shaking"><span class="icon icon-link"></span></a></h2>
<h3 id="내보낼-모듈에-대해서는-export-하기"><strong>내보낼 모듈에 대해서는 export 하기</strong><a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#내보낼-모듈에-대해서는-export-하기"><span class="icon icon-link"></span></a></h3>
<ul>
<li>내보낼 모듈에 대해서는 각각 export 하고 필요로한 컴포넌트에 import 할 경우 tree shaking이 가능합니다.
<ul>
<li>그렇다면 궁금한 점?? re-export 구문으로 설정되어 있는 경우에도 tree shaking이 가능할까?</li>
<li>결론은 됩니다. 그 이유는?? webpack 4 이후부터는 production 빌드 시 optimization 설정 중 providedExports 기본값이 true로 설정됨에 따라서 webpack 빌드 시 구문을 분석해서 최적화 처리를 해줍니다.</li>
</ul>
</li>
</ul>

<h3 id="babelrc-파일-설정하기"><strong>Babelrc 파일 설정하기</strong><a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#babelrc-파일-설정하기"><span class="icon icon-link"></span></a></h3>

<p>이를 방지하기 위해서 <code>.babelrc</code>에서 <code>commonjs</code>로 변환하지 못하도록 설정을 추가해 줘야 합니다.</p>

<h3 id="sideeffects-설정하기"><strong>sideEffects 설정하기</strong><a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#sideeffects-설정하기"><span class="icon icon-link"></span></a></h3>
<p>Webpack은 <strong>사이드 이펙트를 일으킬 수 있는 코드</strong>의 경우, <strong>사용하지 않는 코드라도 트리쉐이킹에서 제외</strong>시킨다.</p>
<p><code>package.json</code> 파일에서 <code>sideEffects</code>를 설정하여, 애플리케이션 전체에서 사이드 이펙트가 발생하지 않을 것이니 트리쉐이킹을 해도 된다고 Webpack 알려주는 용도</p>
<p><code>package.json</code>에 추가하고 싶지 않으면, <code>module.rules</code>를 활용하여 설정할 수 있다.]</p>
<p><a href="https://github.com/webpack/webpack/issues/6065#issuecomment-351060570">Allow app authors to force libraries into sideEffects: false` · Issue #6065 · webpack/webpack</a></p>
<p>단, css-loader 사용하거나 직접 js에서 import로 파일을 가져올 경우 필요한 정보도 빠지는 경우가 생김으로 꼭 sideeffects 배열에 추가해주도록 한다.</p>
