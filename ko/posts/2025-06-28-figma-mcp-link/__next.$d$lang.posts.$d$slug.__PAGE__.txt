<h4 id="figma-api-access-token-발급">Figma API access token 발급<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#figma-api-access-token-발급"><span class="icon icon-link"></span></a></h4>
<h4 id="1단계-전제-조건"><strong>1단계: 전제 조건</strong><a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#1단계-전제-조건"><span class="icon icon-link"></span></a></h4>
<ul>
<li><strong>Node.js</strong> (v16.0 이상)</li>
<li><strong>npm</strong> (v7.0 이상) 또는 pnpm (v8.0 이상)</li>
<li><strong>Figma 계정:</strong> 전문가 또는 기업 계획이 권장됩니다.</li>
<li><strong>Figma API 액세스 토큰:</strong> 읽기 권한이 있는 Figma API 액세스 토큰이 필요합니다.</li>
</ul>
<h4 id="2단계-figma-api-액세스-토큰-받는-방법"><strong>2단계: Figma API 액세스 토큰 받는 방법</strong><a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#2단계-figma-api-액세스-토큰-받는-방법"><span class="icon icon-link"></span></a></h4>
<p>MCP를 Figma와 통합하려면 API 액세스 토큰이 필요합니다. 이 토큰은 MCP가 Figma 계정과 상호작용할 수 있도록 하는 보안 키 역할을 합니다. Figma API 액세스 토큰을 생성하고 저장하는 단계별 가이드는 다음과 같습니다:</p>
<p><strong>Figma 계정 등록:</strong></p>
<ol>
<li><strong>Figma 공식 웹사이트 방문:</strong> <a href="https://www.figma.com/">Figma 웹사이트</a>로 가세요.</li>
<li><strong>가입:</strong> 계정이 없다면 새 계정을 만드세요.</li>
</ol>
<p><strong>2단계: Figma 앱 다운로드:</strong></p>
<ol>
<li><strong>운영 체제 선택:</strong> 운영 체제(Windows, macOS 또는 Linux)와 호환되는 Figma 데스크탑 앱을 다운로드하세요.</li>
<li><strong>앱 설치:</strong> 장치에 Figma를 설정하기 위한 간단한 설치 지침을 따르세요.</li>
</ol>
<p><strong>Figma에 로그인:</strong></p>
<ol>
<li><strong>앱 열기:</strong> Figma 데스크탑 앱을 실행하세요.</li>
<li><strong>로그인:</strong> Figma 자격 증명을 사용하여 로그인하세요.</li>
</ol>
<p><strong>프로필 설정에 접근:</strong></p>
<ol>
<li><strong>프로필 아이콘 클릭:</strong> 사이드바에서 프로필 아이콘(보통 이름 또는 아바타)을 클릭하세요.</li>
<li><strong>드롭다운 메뉴 열기:</strong> 메뉴가 나타나면 <strong>설정</strong>을 클릭하세요.</li>
</ol>
<p><img src="/blog-assets/2025/06/assets/28/image0.png" alt="image.png"></p>
<p><strong>보안 설정으로 이동:</strong></p>
<ol>
<li><strong>보안으로 가기:</strong> 설정 메뉴에서 <strong>보안</strong> 탭을 찾아 클릭하세요.</li>
<li><strong>개인 액세스 토큰 찾기:</strong> <strong>개인 액세스 토큰</strong> 섹션으로 스크롤하세요.</li>
<li><strong>새 토큰 생성:</strong>
<ol>
<li><strong>“새 토큰 생성” 클릭:</strong> 새 토큰을 생성하기 위한 프롬프트가 열립니다.</li>
<li><strong>토큰 이름 지정:</strong> <code>Figma_MCP</code>와 같이 목적을 쉽게 식별할 수 있는 설명적인 이름을 부여하세요.</li>
<li><strong>토큰 생성:</strong> <strong>생성</strong> 버튼을 클릭하여 API 액세스 토큰을 생성하세요.</li>
</ol>
</li>
</ol>
