<h3 id="resolver-summary">resolver summary<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#resolver-summary"><span class="icon icon-link"></span></a></h3>

<ul>
<li>react-hook-form 지원하는 validation library 비교
<ul>
<li>ajv
<ul>
<li>AJV는 JSON 스키마를 사용하여 데이터의 유효성을 검사하며, 이는 다양한 언어로 수행될 수 있습니다.</li>
<li>Github에 별이 12,000개에 달하고 매주 npm 다운로드가 8,500만 건에 달하는 대규모 커뮤니티입니다.</li>
<li>AJV는 현재 json-schema-benchmarks에 따르면 가장 빠른 json 스키마 유효성 검사기 라이브러리입니다.</li>
</ul>
</li>
<li>joi
<ul>
<li>Github에서 약 19,000개의 스타를 보유한 최대 규모의 커뮤니티 및 지원을 제공합니다.</li>
<li>번들 크기는 약 149kb로 축소되었습니다.</li>
<li>서버측을 위해 더 많이 구축되었으며 서버측 작업 시 권장됩니다.</li>
<li>Joi는 매우 큰 API를 가지고 있어 문서화가 잘 되어 있어 학습 곡선이 단축됩니다.</li>
</ul>
</li>
<li>yup
<ul>
<li>Schema는 Joi와 유사하며, 비슷한 방식을 가지고 있습니다.</li>
<li>주로 클라이언트 측에서 사용되며 클라이언트 측 유효성 검사를 지원합니다.</li>
<li>~60kb의 번들 크기가 축소되었습니다. 이는 AJV 및 Joi보다 낮지만 Zod보다 큽니다.</li>
<li>예, 정적 유형 추론을 지원하지만 반드시 TypeScript와 일치할 필요는 없습니다.</li>
</ul>
</li>
<li>zod
<ul>
<li>zod는 정적 유형 추론을 지원하며 TypeScript와 잘 작동합니다.</li>
<li>번들 크기는 약 45kb입니다.</li>
</ul>
</li>
</ul>
</li>
