d:T7035,<h2 id="개요">개요<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#개요"><span class="icon icon-link"></span></a></h2>
<p>본 문서는 Claude Code 플러그인 마켓플레이스의 등록, 설치 및 사용 방법을 기술합니다.</p>
<p><strong>seungah-claude-plugins</strong> 마켓플레이스를 통해 플러그인을 공유하고 있습니다. 현재 다음 4개의 팀별 플러그인으로 구성되어 있습니다.</p>
<p>마켓플레이스 버전: <strong>1.4.0</strong> · 저장소: <a href="https://github.com/seungahhong/seungah-claude-plugins">https://github.com/seungahhong/seungah-claude-plugins</a></p>

<h2 id="마켓플레이스-등록-화면">마켓플레이스 등록 화면<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#마켓플레이스-등록-화면"><span class="icon icon-link"></span></a></h2>

<p>Claude Code 실행 후 /plugin 명령어를 입력합니다.</p>

</blockquote>

<blockquote>
<p>seungah-claude-plugins URL 입력 화면</p>
</blockquote>

<blockquote>
<ul>

<li>space 클릭 해서 선택 → enter 설치 진행</li>
</ul>
</blockquote>

<p>설치할 플러그인을 선택하면 상세 정보가 표시됩니다. 설치 범위(user/project/local scope)를 선택합니다.</p>
<blockquote>
<p>frontend-harness Plugin Details 화면</p>
</blockquote>
<p><strong>5단계. 설치 확인 - settings.local.json</strong></p>
<p>설치가 완료되면 .claude/settings.local.json에 enabledPlugins 설정이 추가됩니다.</p>
<blockquote>
<p>settings.local.json 확인 화면</p>
</blockquote>
<p><strong>6단계. 스킬 실행</strong></p>
<p>설치된 플러그인의 스킬을 /스킬명 형식으로 실행합니다.</p>
<blockquote>
<ul>
<li>/a11y 스킬 실행 화면</li>
<li>나오지 않을 경우 /reload-plugins 실행 후 /(슬러시) 명령어 재시도</li>
</ul>
</blockquote>

<h3 id="사용자가-사용하는-방법">사용자가 사용하는 방법<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#사용자가-사용하는-방법"><span class="icon icon-link"></span></a></h3>
<ol>
<li><strong>마켓플레이스 등록</strong> — Claude Code에서 <code>/plugin marketplace add https://github.com/seungahhong/seungah-claude-plugins</code> (또는 CLI <code>claude plugin add seungahhong/seungah-claude-plugins</code>)</li>
<li><strong>플러그인 설치</strong> — <code>/plugin install frontend-harness@seungah-claude-plugins</code> 처럼 원하는 플러그인만 골라 설치 (user / project / local scope 선택)</li>
<li><strong>스킬 실행</strong> — 설치 후 <code>/planner</code>, <code>/review</code>, <code>/commit</code> 등 슬래시 커맨드로 호출하거나 자연어로 트리거. 목록이 안 보이면 <code>/reload-plugins</code> 후 재시도</li>
<li><strong>업데이트</strong> — 저장소에 변경이 반영되면 <code>/plugin marketplace update seungah-claude-plugins</code> 로 최신화</li>
</ol>
