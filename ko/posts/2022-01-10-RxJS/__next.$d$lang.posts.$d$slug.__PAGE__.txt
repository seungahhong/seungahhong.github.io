e:T151ee,<h2 id="rxjs-개념">RxJS 개념<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#rxjs-개념"><span class="icon icon-link"></span></a></h2>
<p>RxJS는 Reactive Extensions For JavaScript 라이브러리이다.</p>
<p>ReactiveX 는 Observer 패턴, Iterator 패턴, 함수형 프로그래밍을 조합하여 제공한다.</p>
<p>동기와 비동기 처리를 하나의 스트림으로 관리하고 처리가 가능하다.</p>
<ul>
<li>비동기 프로그래밍: 이 문서를 볼 정도면 설명이 필요 없을 것 같다.</li>
<li>함수형 프로그래밍: 순수함수, 고차함수, 일급 함수</li>
<li>데이터스트림: file stream, event stream, http stream 의 친구로 data 식 표현</li>
<li>이터레이터: iterator pattern(ES6)</li>
</ul>
<p><img src="/blog-assets/2022/01/assets/10/Untitled.png" alt="Untitled"></p>
<p>Array, Set, Map 과 같이 리스트 데이터들은 기본적으로 Iterable이며 Iterator를 가지고 있으며, 이는 곧 Protocol을 만족한다는 의미, spread/rest 연산도 iterator문법을 따름</p>
<ul>
<li>옵져버: 디자인패턴 책의 옵져버패턴 단원 참조, 자바스크립트에선 이미 이벤트리스너가 옵져버 패턴이다.</li>
<li>옵져버블: 특정 객체를 관찰하는 옵저버에게 여러 이벤트나 값을 전파하는 역할</li>
<li>풀: 데이터를 받을지 결정</li>
<li>푸쉬: 데이터를 보낼지 결정</li>
<li>싱글: 하나의 값이나 이벤트를 다룸</li>
<li>멀티플: 여러 개의 값이나 이벤트를 다룸</li>
</ul>

<h3 id="promise-vs-observable">Promise vs. Observable<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#promise-vs-observable"><span class="icon icon-link"></span></a></h3>
<h4 id="실행-시점"><strong>실행 시점</strong><a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#실행-시점"><span class="icon icon-link"></span></a></h4>
<ul>
<li>Promise는 객체를 생성할 때 바로 실행되어 즉시 로딩(eager)이라 부른다. 모든 <code>then()</code>은 같은 계산 값을 공유한다.</li>
</ul>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="jsx" data-theme="github-light-high-contrast github-dark-high-contrast"><code data-language="jsx" data-theme="github-light-high-contrast github-dark-high-contrast" style="display: grid;"><span data-line=""><span style="--shiki-light:#66707B;--shiki-dark:#BDC4CC">// 최초 실행 (생성 및 실행)</span></span>
<span data-line=""><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492">let</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6"> promise </span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492">=</span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492"> new</span><span style="--shiki-light:#023B95;--shiki-dark:#91CBFF"> Promise</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">((</span><span style="--shiki-light:#702C00;--shiki-dark:#FFB757">resolve</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">, </span><span style="--shiki-light:#702C00;--shiki-dark:#FFB757">reject</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">) </span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492">=></span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6"> {</span></span>
<span data-line=""><span style="--shiki-light:#66707B;--shiki-dark:#BDC4CC">  // ...</span></span>
<span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">});</span></span>
<span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">promise.</span><span style="--shiki-light:#622CBC;--shiki-dark:#DBB7FF">then</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">(</span><span style="--shiki-light:#702C00;--shiki-dark:#FFB757">value</span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492"> =></span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6"> {</span></span>
<span data-line=""><span style="--shiki-light:#66707B;--shiki-dark:#BDC4CC">  // 결과 처리</span></span>
<span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">});</span></span></code></pre></figure>
<ul>
<li>Observable은 소비자가 구독(subscription)하기 전까지는 실행되지 않아 지연 로딩(lazy)이라 부른다. <code>subscribe()</code>는 여러 번 호출될 수 있으며, 각각의 구독은 모두 자신만의 계산 값을 갖고 있다.</li>
</ul>

<span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">});</span></span>
<span data-line=""> </span>
<span data-line=""><span style="--shiki-light:#66707B;--shiki-dark:#BDC4CC">// 최초 실행 (구독)</span></span>
<span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">observable$.</span><span style="--shiki-light:#622CBC;--shiki-dark:#DBB7FF">subscribe</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">(</span><span style="--shiki-light:#702C00;--shiki-dark:#FFB757">value</span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492"> =></span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6"> {</span></span>
<span data-line=""><span style="--shiki-light:#66707B;--shiki-dark:#BDC4CC">  // observer 처리</span></span>
<span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">});</span></span></code></pre></figure>

<ul>
<li>Promise는 하나만 보낼 수 있으며, 여러 개 보낼 경우 나중에 보낸 건 무시된다.</li>

<li>Observable은 데이터를 여러 개 보낼 수 있다.</li>

<h4 id="조작과-반환"><strong>조작과 반환</strong><a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#조작과-반환"><span class="icon icon-link"></span></a></h4>
<ul>
<li>Promise는 <code>then()</code> 하나로 데이터의 조작과 반환을 같이 진행한다.</li>
</ul>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="jsx" data-theme="github-light-high-contrast github-dark-high-contrast"><code data-language="jsx" data-theme="github-light-high-contrast github-dark-high-contrast" style="display: grid;"><span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">promise.</span><span style="--shiki-light:#622CBC;--shiki-dark:#DBB7FF">then</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">(</span><span style="--shiki-light:#702C00;--shiki-dark:#FFB757">v</span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492"> =></span><span style="--shiki-light:#023B95;--shiki-dark:#91CBFF"> 2</span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492"> *</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6"> v);</span></span></code></pre></figure>
<ul>
<li>Observable은 데이터의 조작과 구독(반환)을 나눌 수 있다. 오직 구독자가 있을 때만 subscriber 함수가 실행되어 값을 계산한다. 다른 곳에서 데이터를 복잡하게 가공해야 한다면 Observable이 더 효율적이다.</li>
</ul>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="jsx" data-theme="github-light-high-contrast github-dark-high-contrast"><code data-language="jsx" data-theme="github-light-high-contrast github-dark-high-contrast" style="display: grid;"><span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">observable$.</span><span style="--shiki-light:#622CBC;--shiki-dark:#DBB7FF">pipe</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">(</span><span style="--shiki-light:#622CBC;--shiki-dark:#DBB7FF">map</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">(</span><span style="--shiki-light:#702C00;--shiki-dark:#FFB757">v</span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492"> =></span><span style="--shiki-light:#023B95;--shiki-dark:#91CBFF"> 2</span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492"> *</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6"> v));</span></span></code></pre></figure>
<h4 id="취소해제"><strong>취소(해제)</strong><a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#취소해제"><span class="icon icon-link"></span></a></h4>
<ul>
<li>Promise는 실행 도중에 취소할 수 없지만, Observable은 구독을 취소(해제)할 수 있다. 구독 취소는 이벤트 리스터가 받을 값을 제거하고, subscriber 함수에게 취소하라고 알린다.</li>
</ul>

<h3 id="오퍼레이터operator">오퍼레이터(Operator)<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#오퍼레이터operator"><span class="icon icon-link"></span></a></h3>
<p>파이프형 연산자는 Observable을 input처럼 취해서 다른 Observable을 반환하는 함수</p>
<ul>
<li><strong>Operator는 항상 새로운 Observable을 만든다.</strong></li>
<li><strong>Operator는 항상 Observable을 반환 한다.</strong></li>
<li><strong>Operator이전의 Source Observable에 대해서는 Immutable해야 한다.</strong></li>
