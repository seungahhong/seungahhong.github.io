이번 주 패키지 릴리스 정리 — 2026-11-07

홍홍승아·2026.11.07·16분

✍️ 한 줄 요약

Next.js(16.4.5·15.5.29)가 엣지 응답의 내부 쿠키 헤더 제거 등 보안성 수정을 낸 데 이어, Nuxt 4.6.4는 개발 서버 Host 헤더 검증과 x-forwarded-proto 신뢰 범위 제한을, Hono 4.13.16은 JWT 서명 검증 강화와 라우터·mount 경로 처리 수정을 냈습니다. Rolldown 1.3.0은 CLI에서 --input과 위치 인자를 같이 쓰면 거부하는 breaking change(기존 코드를 고쳐야 하는 변경)가 있고, Omarchy는 4.5.0(🔺 메이저 라인)이 나왔습니다.

이번 주 한눈에 보기

기간은 2026-10-31 ~ 2026-11-07(KST)이며, 추적 중인 87개 패키지 가운데 28개의 변경점을 확인했습니다. 변경점을 읽지 못해 뺀 패키지는 마무리 섹션에 적었습니다.

이번 주는 GitHub 릴리스 페이지를 읽을 수 없어, CHANGELOG 파일이 있는 패키지는 그 파일을, 없는 패키지는 새 태그까지의 변경 이력(커밋 제목)을 읽고 정리했습니다. 이 경우 릴리스 공지는 없음으로 표시했습니다.

패키지별 변경 내용

astro 7.4.7

JavaScript 웹 프레임워크입니다.

무엇이 바뀌었나 — 패치 릴리스 3개가 이어졌습니다. 7.4.7은 이미지 엔드포인트가 대소문자만 다른 디렉토리를 빌드 폴더 안에 있는 것으로 잘못 취급하던 문제를 고쳤습니다. 7.4.6은 astro check가 오류가 있어도 종료 코드 0을 반환하던 문제, glob() 로더의 파일 처리, 첫 로드 때 불필요한 페이지 새로고침, 온디맨드 렌더링 페이지의 i18n fallback을 고쳤습니다. 7.4.5는 astro dev status 같은 백그라운드 명령과 import.meta.env 값 처리, 잘못된 퍼센트 인코딩 경로 요청을 다뤘습니다.

업그레이드할 때 확인할 점 — CI에서 astro check를 쓴다면 이전에는 통과하던 오류가 이제 실패로 잡힐 수 있으니 한 번 돌려 보세요. 그 외에는 그대로 올려도 됩니다.

pnpm v12.18.0 · v11.28.11

Node.js 패키지 매니저입니다.

무엇이 바뀌었나 — 변경 이력상 12.18.0의 중심은 패키지를 플랫폼별 변형(variants)과 함께 게시하고 설치하는 기능입니다. 여러 머신에서 올린 변형을 한 버전으로 묶어 게시하고, 변형만 있는 버전도 설치할 수 있습니다. supportedArchitectures가 플랫폼 태그로 읽히고, pack --json에 아카이브별 무결성 값과 크기가 출력됩니다. 정의되지 않은 필수 peer 제공자에 대한 경고가 추가됐고, 상대 경로 file: peer·루트 override·catalog 경로 해석 버그가 고쳐졌습니다.

업그레이드할 때 확인할 점 — 변경 이력만 읽은 정리라 breaking change 여부는 확인하지 못했습니다. 11.x 라인은 11.28.11로 올리는 패치이니, 12로 넘어가는 경우에만 공식 마이그레이션 안내를 따로 확인하세요.

업그레이드할 때 확인할 점 — 인증 정책에서 Host 매칭이 대소문자 구분 없이 바뀌므로 정책 의도와 맞는지 확인하세요.

무엇이 바뀌었나 — 개발 서버가 예상치 못한 Host 헤더를 거부하고 devServer.allowedHosts 설정이 생겼습니다. x-forwarded-proto는 허용하도록 설정한 경우에만 신뢰하고, 신뢰할 수 없는 오류의 세부 정보를 노출하지 않습니다. 대소문자를 구분하지 않는 라우트 규칙의 와일드카드 꼬리, 인코딩된 슬래시 경로, 섬(island) 해시 인코딩이 고쳐졌습니다.

업그레이드할 때 확인할 점 — 개발 서버를 별도 도메인이나 터널로 열어 쓴다면 devServer.allowedHosts를 설정해야 할 수 있습니다.
