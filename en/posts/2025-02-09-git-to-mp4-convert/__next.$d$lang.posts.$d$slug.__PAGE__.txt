24:T70f9,<h2 id="overview">Overview<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#overview"><span class="icon icon-link"></span></a></h2>
<p>Among our resources, the gif format tends to be large in size. To reduce the amount of data users need to download and to improve loading speed, I carried out a performance improvement task that converts gifs to the mp4 video format, which provides more efficient compression, and applied this feature to the service.</p>
<h2 id="requirements-analysis">Requirements Analysis<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#requirements-analysis"><span class="icon icon-link"></span></a></h2>
<ul>
<li>Conversion format
<ul>
<li>img > gif → video > mp4</li>
<li>When an mp4 file with the same filename exists, load the mp4 instead of the gif</li>
</ul>
</li>
<li>Applying a placeholder
<ul>
<li>Set the placeholder height based on the image width and height values stored in the dataset</li>
</ul>
</li>
<li>Recalculating the size
<ul>
<li>Recalculate the width/height when a browser resize occurs</li>
</ul>
</li>
<li>Viewport-based mp4 loading/playback/pause
<ul>
<li>Load the mp4 when it reaches the viewport region</li>
</ul>
</li>
<li>Provide the same behavior as a gif
<ul>
<li>autoplay, mute, loop, playinline</li>
</ul>
</li>
</ul>
