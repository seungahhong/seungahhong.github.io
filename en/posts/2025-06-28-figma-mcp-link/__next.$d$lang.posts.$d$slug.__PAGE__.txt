<h2 id="how-to-integrate-with-copilot">How to Integrate with Copilot<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#how-to-integrate-with-copilot"><span class="icon icon-link"></span></a></h2>
<h4 id="issuing-a-figma-api-access-token">Issuing a Figma API access token<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#issuing-a-figma-api-access-token"><span class="icon icon-link"></span></a></h4>
<h4 id="step-1-prerequisites"><strong>Step 1: Prerequisites</strong><a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#step-1-prerequisites"><span class="icon icon-link"></span></a></h4>
<ul>
<li><strong>Node.js</strong> (v16.0 or higher)</li>
<li><strong>npm</strong> (v7.0 or higher) or pnpm (v8.0 or higher)</li>
<li><strong>Figma account:</strong> A Professional or Enterprise plan is recommended.</li>
<li><strong>Figma API access token:</strong> You need a Figma API access token with read permissions.</li>
</ul>
<h4 id="step-2-how-to-get-a-figma-api-access-token"><strong>Step 2: How to get a Figma API access token</strong><a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#step-2-how-to-get-a-figma-api-access-token"><span class="icon icon-link"></span></a></h4>
<p>To integrate MCP with Figma, you need an API access token. This token acts as a security key that allows MCP to interact with your Figma account. Here is a step-by-step guide to creating and storing a Figma API access token:</p>
<p><strong>Register a Figma account:</strong></p>
<ol>
<li><strong>Visit the official Figma website:</strong> Go to the <a href="https://www.figma.com/">Figma website</a>.</li>
<li><strong>Sign up:</strong> If you do not have an account, create a new one.</li>
</ol>
<p><strong>Step 2: Download the Figma app:</strong></p>
<ol>
<li><strong>Choose your operating system:</strong> Download the Figma desktop app compatible with your operating system (Windows, macOS, or Linux).</li>
<li><strong>Install the app:</strong> Follow the simple installation instructions to set up Figma on your device.</li>
</ol>
<p><strong>Log in to Figma:</strong></p>
<ol>
<li><strong>Open the app:</strong> Launch the Figma desktop app.</li>
<li><strong>Log in:</strong> Log in using your Figma credentials.</li>
</ol>
<p><strong>Access your profile settings:</strong></p>
<ol>
<li><strong>Click the profile icon:</strong> In the sidebar, click the profile icon (usually your name or avatar).</li>
<li><strong>Open the dropdown menu:</strong> When the menu appears, click <strong>Settings</strong>.</li>
</ol>
<p><img src="/blog-assets/2025/06/assets/28/image0.png" alt="image.png"></p>
<p><strong>Go to security settings:</strong></p>
<ol>
<li><strong>Go to Security:</strong> In the settings menu, find and click the <strong>Security</strong> tab.</li>
<li><strong>Find personal access tokens:</strong> Scroll down to the <strong>Personal access tokens</strong> section.</li>
<li><strong>Generate a new token:</strong>
<ol>
<li><strong>Click "Generate new token":</strong> A prompt to create a new token opens.</li>
<li><strong>Name the token:</strong> Give it a descriptive name that makes its purpose easy to identify, such as <code>Figma_MCP</code>.</li>
<li><strong>Create the token:</strong> Click the <strong>Generate</strong> button to create the API access token.</li>
</ol>
</li>
</ol>
<p><img src="/blog-assets/2025/06/assets/28/image1.png" alt="image.png"></p>
<p>How to configure the .vscode > mcp.json file</p>
<ul>
<li>Only create this file if an mcp.json file does not already exist.</li>
<li>Only for Copilot, you must put it under the <code>servers</code> object property.</li>
</ul>
