<h4 id="fastapi-01631--01630">FastAPI 0.163.1 · 0.163.0<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#fastapi-01631--01630"><span class="icon icon-link"></span></a></h4>
<p>A Python web framework.</p>
<p><strong>What changed</strong> — 0.163.0 adds <code>Depends(max_concurrency=...)</code>, which lets you limit how many instances of a given dependency can run at the same time. If you wrap resources that should not be hit all at once, such as an external API or database connections, in a dependency, you can now cap their concurrency without writing your own semaphore code. 0.163.1 fixes the OpenAPI document being generated incorrectly when a response model contains a nested computed field.</p>
<p><strong>What to check when upgrading</strong> — The new option is an addition that only affects places where you use it. The Python 3.10 support drop in 0.162.6, covered in the previous post, still applies, so if you are on 3.10 you need to upgrade Python first.</p>
<p>Release notice: <a href="https://github.com/fastapi/fastapi/blob/master/docs/en/docs/release-notes.md">release-notes</a></p>
<h4 id="grafana-12415">Grafana 12.4.15<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#grafana-12415"><span class="icon icon-link"></span></a></h4>
<p>A metrics dashboard.</p>
<p><strong>What changed</strong> — This is a release on the 12.4 maintenance line, published the same day as the 13.x releases covered in the previous post. It contains 8 security fixes: CVE-2026-102589, CVE-2026-106472, CVE-2026-106475, CVE-2026-107365, CVE-2026-107509, CVE-2026-111000, CVE-2026-81843 and CVE-2026-82014. The CHANGELOG lists only the numbers and does not say what was at risk. moment-timezone was also bumped to reflect the 2026 time zone changes.</p>
<p><strong>What to check when upgrading</strong> — If you still run the 12.4 line, upgrade to 12.4.15. Check the official security advisories for the impact of each CVE.</p>
<p>Release notice: <a href="https://github.com/grafana/grafana/blob/main/CHANGELOG.md">CHANGELOG</a></p>
<h4 id="biome-v268">Biome v2.6.8<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#biome-v268"><span class="icon icon-link"></span></a></h4>
<p>A frontend toolchain (formatter and linter).</p>
<p><strong>What changed</strong> — A large batch of nursery (experimental) rules was added, including <code>noBufferConstructor</code>, <code>noDynamicRequire</code>, <code>noMisusedSpread</code>, <code>useSpyOn</code>, <code>noTailwindRestrictedClasses</code>, and rules for Vue and YAML. Type inference now narrows types after <code>typeof</code> and equality checks and evaluates conditional types such as <code>T extends U ? X : Y</code>, reducing false positives in type-aware rules. Linting files without suppression comments is up to 61% faster, and several bugs were fixed, such as the HTML formatter printing a comment twice or deleting comments after Svelte block delimiters.</p>
<p><strong>What to check when upgrading</strong> — The new rules are nursery rules, so they have no effect unless you enable them. However, Biome now reports an error when a GritQL plugin file name contains invalid characters, so check your file names if you use plugins.</p>
<p>Release notice: <a href="https://github.com/biomejs/biome/blob/main/packages/@biomejs/biome/CHANGELOG.md">CHANGELOG</a></p>
<h4 id="react-native-skia-v3102--v2155--v2154--v2153">React Native Skia v3.10.2 · v2.15.5 · v2.15.4 · v2.15.3<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#react-native-skia-v3102--v2155--v2154--v2153"><span class="icon icon-link"></span></a></h4>
<p>A 2D graphics library for React Native.</p>
<p><strong>What changed</strong> — According to the commit history, v3.10.2 paces a canvas's frames with a single scheduler and holds a present for the GPU on Android, draws <code>&#x3C;Text></code> with a cached text blob, and moves CAMetalLayer color space tagging on iOS to the main thread. The 2.x line (v2.15.3 to v2.15.5) backports fixes from 3.x, including web improvements, rounding the iOS canvas size to the pixel grid, Android TextureView buffer handling, and keeping the frame of a disposed canvas.</p>
<p><strong>What to check when upgrading</strong> — This summary is based on commit history only, so we could not confirm whether there are breaking changes. If you are still on 2.x, you can get these fixes by upgrading to v2.15.5 within the same major version.</p>
<p>Release notice: None</p>
