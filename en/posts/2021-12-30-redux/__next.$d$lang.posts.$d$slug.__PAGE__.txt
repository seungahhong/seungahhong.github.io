1b:T316a,<h3 id="redux-concepts">Redux Concepts<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#redux-concepts"><span class="icon icon-link"></span></a></h3>
<h4 id="action">Action<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#action"><span class="icon icon-link"></span></a></h4>
<p>When some change needs to happen to the state, we dispatch what is called an action. An action is represented as a single object, and an action object takes the following form.</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="javascript" data-theme="github-light-high-contrast github-dark-high-contrast"><code data-language="javascript" data-theme="github-light-high-contrast github-dark-high-contrast" style="display: grid;"><span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">{</span></span>
<span data-line=""><span style="--shiki-light:#702C00;--shiki-dark:#FFB757">  type</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">: </span><span style="--shiki-light:#032563;--shiki-dark:#ADDCFF">'TOGGLE_VALUE'</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">;</span></span>
<span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">}</span></span></code></pre></figure>
<p>An action object must always have a type field, and any other values can be added at the developer's discretion.</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="javascript" data-theme="github-light-high-contrast github-dark-high-contrast"><code data-language="javascript" data-theme="github-light-high-contrast github-dark-high-contrast" style="display: grid;"><span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">{</span></span>

<h4 id="action-creator">Action Creator<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#action-creator"><span class="icon icon-link"></span></a></h4>
<p>An action creator is a function that creates an action. It simply takes parameters and turns them into an action object.</p>

<h4 id="reducer">Reducer<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#reducer"><span class="icon icon-link"></span></a></h4>
<p>A reducer is a function that brings about change. A reducer takes two parameters.</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="javascript" data-theme="github-light-high-contrast github-dark-high-contrast"><code data-language="javascript" data-theme="github-light-high-contrast github-dark-high-contrast" style="display: grid;"><span data-line=""><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492">function</span><span style="--shiki-light:#622CBC;--shiki-dark:#DBB7FF"> reducer</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">(</span><span style="--shiki-light:#702C00;--shiki-dark:#FFB757">state</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">, </span><span style="--shiki-light:#702C00;--shiki-dark:#FFB757">action</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">) {</span></span>
<span data-line=""><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492">  if</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6"> (state </span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492">===</span><span style="--shiki-light:#023B95;--shiki-dark:#91CBFF"> undefined</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">) {</span></span>
<span data-line=""><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492">    return</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6"> { color: </span><span style="--shiki-light:#032563;--shiki-dark:#ADDCFF">'yellow'</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6"> };</span></span>
<span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">  }</span></span>
<span data-line=""> </span>
<span data-line=""><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492">  var</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6"> newState;</span></span>
<span data-line=""><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492">  if</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6"> (action.type </span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492">===</span><span style="--shiki-light:#032563;--shiki-dark:#ADDCFF"> 'CHANGE_COLOR'</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">) {</span></span>

<span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">  }</span></span>
<span data-line=""> </span>
<span data-line=""><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492">  return</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6"> newState;</span></span>
<span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">}</span></span></code></pre></figure>
<p>A reducer references the current state and the received action to create and return a new state.</p>
<h4 id="store">Store<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#store"><span class="icon icon-link"></span></a></h4>
<p>In Redux, you create a single store per application. The store holds the current app state and the reducer, along with a few additional built-in functions.</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="javascript" data-theme="github-light-high-contrast github-dark-high-contrast"><code data-language="javascript" data-theme="github-light-high-contrast github-dark-high-contrast" style="display: grid;"><span data-line=""><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492">var</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6"> store </span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492">=</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6"> Redux.</span><span style="--shiki-light:#622CBC;--shiki-dark:#DBB7FF">createStore</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">(reducer);</span></span></code></pre></figure>
<h4 id="dispatch">dispatch<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#dispatch"><span class="icon icon-link"></span></a></h4>
<p>dispatch is one of the store's built-in functions. You can think of dispatch as the act of firing an action. You pass an action to the dispatch function as a parameter, like dispatch(action).</p>
<p>When you call it this way, the store runs the reducer function, and if there is logic that handles that action, it references the action to create a new state.</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="javascript" data-theme="github-light-high-contrast github-dark-high-contrast"><code data-language="javascript" data-theme="github-light-high-contrast github-dark-high-contrast" style="display: grid;"><span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">store.</span><span style="--shiki-light:#622CBC;--shiki-dark:#DBB7FF">dispatch</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">({ type: </span><span style="--shiki-light:#032563;--shiki-dark:#ADDCFF">'CHANGE_COLOR'</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">, color: </span><span style="--shiki-light:#032563;--shiki-dark:#ADDCFF">'red'</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6"> });</span></span></code></pre></figure>
<h4 id="subscribe">subscribe<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#subscribe"><span class="icon icon-link"></span></a></h4>
<p>subscribe is also one of the store's built-in functions. The subscribe function takes a function as its parameter. If you pass a specific function to subscribe, that function is called every time an action is dispatched.</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="javascript" data-theme="github-light-high-contrast github-dark-high-contrast"><code data-language="javascript" data-theme="github-light-high-contrast github-dark-high-contrast" style="display: grid;"><span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">store.</span><span style="--shiki-light:#622CBC;--shiki-dark:#DBB7FF">subscribe</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">(green);</span></span></code></pre></figure>
