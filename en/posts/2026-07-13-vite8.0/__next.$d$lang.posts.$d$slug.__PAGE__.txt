f:T5b86,<h2 id="vite-80-release-the-unified-toolchain-and-migration-guide">Vite 8.0 Release: The Unified Toolchain and Migration Guide<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#vite-80-release-the-unified-toolchain-and-migration-guide"><span class="icon icon-link"></span></a></h2>
<p>On March 12, 2026, Vite 8.0 was officially released. The heart of this major version is the <strong>Unified Toolchain</strong>: the default bundler switches to Rolldown, and the transformation and minification that esbuild used to handle are now done by Oxc. It is regarded as the most significant architectural change since Vite 2. Weekly downloads have reached 65 million.</p>

<h3 id="key-changes">Key Changes<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#key-changes"><span class="icon icon-link"></span></a></h3>
<h4 id="1-the-unified-toolchain">1. The Unified Toolchain<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#1-the-unified-toolchain"><span class="icon icon-link"></span></a></h4>
<p>The biggest change in Vite 8 is a toolchain aligned into one. Previously, Vite used a dual-bundler setup — esbuild during development and Rollup for production builds — but Vite 8 unifies them.</p>
<p><strong>The three components:</strong></p>
<ul>
<li><strong>Vite</strong> — the build tool</li>
<li><strong>Rolldown</strong> — the bundler (Rust-based)</li>
<li><strong>Oxc</strong> — the compiler (parsing, transforming, minifying)</li>
</ul>
<p>This alignment guarantees consistent behavior across the entire pipeline of parsing, resolving, transforming, and minifying.</p>
<h4 id="2-rolldown-adopted-as-the-default-bundler">2. Rolldown Adopted as the Default Bundler<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#2-rolldown-adopted-as-the-default-bundler"><span class="icon icon-link"></span></a></h4>
<p><strong>Rolldown</strong>, the Rust-based bundler offered experimentally in Vite 7, is now the default, replacing esbuild and Rollup.</p>
<p><strong>Main effects:</strong></p>
<ul>
<li><strong>Up to 10–30x faster builds</strong> (while maintaining plugin compatibility)</li>
<li>Eliminates bundler inconsistency between development and production</li>
<li>The most significant architectural change since Vite 2</li>
</ul>

<h4 id="3-oxc-based-transformation-and-minification">3. Oxc-based Transformation and Minification<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#3-oxc-based-transformation-and-minification"><span class="icon icon-link"></span></a></h4>
<p>JavaScript transformation and minification have moved from esbuild to <strong>Oxc</strong>.</p>
<ul>
<li><strong>JS transformation</strong>: Oxc replaces esbuild (<code>esbuild</code> option → <code>oxc</code>)</li>
<li><strong>JS minification</strong>: uses the Oxc Minifier</li>
<li><strong>CSS minification</strong>: Lightning CSS is now the default</li>
<li>Note: Oxc does not support native decorator lowering, so use a Babel/SWC plugin when needed.</li>
</ul>
<h4 id="4-nodejs-support-requirements">4. Node.js Support Requirements<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#4-nodejs-support-requirements"><span class="icon icon-link"></span></a></h4>
<p>Vite 8 requires <strong>Node.js 20.19+ or 22.12+</strong> (unchanged from Vite 7).</p>

<h3 id="conclusion">Conclusion<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#conclusion"><span class="icon icon-link"></span></a></h3>
<p>Vite 8.0 is fundamentally about moving to a <strong>Unified Toolchain</strong> that ties development and production together. Adopting Rolldown and Oxc delivers up to 10–30x faster builds, but it requires some configuration changes such as bundler options (<code>rollupOptions</code> → <code>rolldownOptions</code>) and transformation options (<code>esbuild</code> → <code>oxc</code>).</p>
<p><strong>Key checklist:</strong></p>
<ul>
<li>✅ Confirm Node.js 20.19+ or 22.12+</li>
<li>✅ Review the raised browser targets</li>
<li>✅ Migrate <code>rollupOptions</code> → <code>rolldownOptions</code></li>
<li>✅ Check <code>esbuild</code> → <code>oxc</code> options, keep <code>minify: 'esbuild'</code> if needed</li>
<li>✅ Verify CommonJS interop behavior (<code>legacy.inconsistentCjsInterop</code>)</li>
<li>✅ Prepare a Babel/SWC plugin if you use decorators</li>
</ul>
