22:T15103,<h2 id="rxjs-concepts">RxJS Concepts<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#rxjs-concepts"><span class="icon icon-link"></span></a></h2>
<p>RxJS is the Reactive Extensions For JavaScript library.</p>
<p>ReactiveX combines the Observer pattern, the Iterator pattern, and functional programming into a single offering.</p>
<p>It lets you manage and handle both synchronous and asynchronous processing as a single stream.</p>
<ul>
<li>Asynchronous programming: if you are reading this document, you probably do not need an explanation.</li>
<li>Functional programming: pure functions, higher-order functions, first-class functions</li>
<li>Data stream: a data-style representation, a companion to file streams, event streams, and http streams</li>
<li>Iterator: the iterator pattern (ES6)</li>
</ul>
<p><img src="/blog-assets/2022/01/assets/10/Untitled.png" alt="Untitled"></p>
<p>List data such as Array, Set, and Map are Iterable by default and have an Iterator, which means they satisfy the protocol. The spread/rest operations also follow the iterator syntax.</p>
<ul>
<li>Observer: refer to the Observer pattern chapter in design pattern books. In JavaScript, event listeners are already an example of the Observer pattern.</li>
<li>Observable: responsible for propagating multiple events or values to observers that watch a particular object</li>
<li>Pull: decides whether to receive data</li>
<li>Push: decides whether to send data</li>
<li>Single: handles a single value or event</li>
<li>Multiple: handles multiple values or events</li>
</ul>

<p><strong>queueScheduler</strong> : placed directly onto the call stack. Rarely used.</p>

<h3 id="promise-vs-observable">Promise vs. Observable<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#promise-vs-observable"><span class="icon icon-link"></span></a></h3>
<h4 id="execution-timing"><strong>Execution Timing</strong><a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#execution-timing"><span class="icon icon-link"></span></a></h4>
<ul>
<li>A Promise runs as soon as the object is created and is loaded immediately, which is why it is called eager. Every <code>then()</code> shares the same computed value.</li>
</ul>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="jsx" data-theme="github-light-high-contrast github-dark-high-contrast"><code data-language="jsx" data-theme="github-light-high-contrast github-dark-high-contrast" style="display: grid;"><span data-line=""><span style="--shiki-light:#66707B;--shiki-dark:#BDC4CC">// 최초 실행 (생성 및 실행)</span></span>
<span data-line=""><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492">let</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6"> promise </span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492">=</span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492"> new</span><span style="--shiki-light:#023B95;--shiki-dark:#91CBFF"> Promise</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">((</span><span style="--shiki-light:#702C00;--shiki-dark:#FFB757">resolve</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">, </span><span style="--shiki-light:#702C00;--shiki-dark:#FFB757">reject</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">) </span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492">=></span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6"> {</span></span>
<span data-line=""><span style="--shiki-light:#66707B;--shiki-dark:#BDC4CC">  // ...</span></span>
<span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">});</span></span>
<span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">promise.</span><span style="--shiki-light:#622CBC;--shiki-dark:#DBB7FF">then</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">(</span><span style="--shiki-light:#702C00;--shiki-dark:#FFB757">value</span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492"> =></span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6"> {</span></span>
<span data-line=""><span style="--shiki-light:#66707B;--shiki-dark:#BDC4CC">  // 결과 처리</span></span>

<ul>
<li>An Observable does not run until a consumer subscribes to it, which is why it is called lazy. <code>subscribe()</code> can be called multiple times, and each subscription has its own computed value.</li>
</ul>

<span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">});</span></span>
<span data-line=""> </span>
<span data-line=""><span style="--shiki-light:#66707B;--shiki-dark:#BDC4CC">// 최초 실행 (구독)</span></span>

<ul>
<li>A Promise can send only one value, and if you send several, the ones sent later are ignored.</li>
</ul>

<span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">});</span></span>

<h4 id="manipulation-and-return"><strong>Manipulation and Return</strong><a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#manipulation-and-return"><span class="icon icon-link"></span></a></h4>
<ul>
<li>A Promise handles both manipulating and returning data with a single <code>then()</code>.</li>
</ul>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="jsx" data-theme="github-light-high-contrast github-dark-high-contrast"><code data-language="jsx" data-theme="github-light-high-contrast github-dark-high-contrast" style="display: grid;"><span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">promise.</span><span style="--shiki-light:#622CBC;--shiki-dark:#DBB7FF">then</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">(</span><span style="--shiki-light:#702C00;--shiki-dark:#FFB757">v</span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492"> =></span><span style="--shiki-light:#023B95;--shiki-dark:#91CBFF"> 2</span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492"> *</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6"> v);</span></span></code></pre></figure>
<ul>
<li>An Observable can separate manipulating and subscribing (returning) data. The subscriber function runs and computes its value only when there is a subscriber. If you need to process data in a complex way elsewhere, an Observable is more efficient.</li>
</ul>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="jsx" data-theme="github-light-high-contrast github-dark-high-contrast"><code data-language="jsx" data-theme="github-light-high-contrast github-dark-high-contrast" style="display: grid;"><span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">observable$.</span><span style="--shiki-light:#622CBC;--shiki-dark:#DBB7FF">pipe</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">(</span><span style="--shiki-light:#622CBC;--shiki-dark:#DBB7FF">map</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">(</span><span style="--shiki-light:#702C00;--shiki-dark:#FFB757">v</span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492"> =></span><span style="--shiki-light:#023B95;--shiki-dark:#91CBFF"> 2</span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492"> *</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6"> v));</span></span></code></pre></figure>
<h4 id="cancellation-release"><strong>Cancellation (Release)</strong><a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#cancellation-release"><span class="icon icon-link"></span></a></h4>
<ul>
<li>A Promise cannot be cancelled mid-execution, but an Observable can cancel (release) its subscription. Cancelling a subscription removes the value the event listener would receive and tells the subscriber function to cancel.</li>
</ul>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="jsx" data-theme="github-light-high-contrast github-dark-high-contrast"><code data-language="jsx" data-theme="github-light-high-contrast github-dark-high-contrast" style="display: grid;"><span data-line=""><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492">const</span><span style="--shiki-light:#023B95;--shiki-dark:#91CBFF"> subscription</span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492"> =</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6"> observable$.</span><span style="--shiki-light:#622CBC;--shiki-dark:#DBB7FF">subscribe</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">(() </span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492">=></span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6"> {</span></span>
<span data-line=""><span style="--shiki-light:#66707B;--shiki-dark:#BDC4CC">  // ...</span></span>
<span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">});</span></span>
<span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">subscription.</span><span style="--shiki-light:#622CBC;--shiki-dark:#DBB7FF">unsubscribe</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">();</span></span></code></pre></figure>
<h3 id="operators">Operators<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#operators"><span class="icon icon-link"></span></a></h3>

<ul>
<li><strong>An operator always creates a new Observable.</strong></li>
<li><strong>An operator always returns an Observable.</strong></li>
