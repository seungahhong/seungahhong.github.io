React Form vs React-Hook-Form

Introduction to react-hook-form and its advantages

A library that makes building forms in React easy. As stated in the official docs, it is performant, flexible, and excellent at validation.

Advantages

  • less code, easier inputs
  • don’t deal with events
  • better validation
    • Controlled at the JavaScript layer rather than through HTML attributes
      • Can defend against malicious attacks (if HTML attributes are modified, the browser fails to recognize them: required, minLength, etc.)
  • better error
  • have control over inputs
  • Supports TS out of the box
  • Uses functional components (Hook API)

Uncontrolled component vs Controlled component

Uncontrolled component
  • Instead of writing an event handler for every state update, it uses a ref to pull form values from the DOM and process them.
  • PULL the value
Controlled component
  • An approach that turns the information currently entered into an HTML element into state, and updates the HTML element's value based on that changed state.
  • PUSH the value
  • The material ui library sometimes passes a Controlled Component that does not control the ref attribute.
