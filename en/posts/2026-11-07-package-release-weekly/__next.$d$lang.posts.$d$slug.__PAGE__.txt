<h4 id="astro-747">astro 7.4.7<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#astro-747"><span class="icon icon-link"></span></a></h4>
<p>A JavaScript web framework.</p>
<p><strong>What changed</strong> — Three patch releases landed. 7.4.7 fixed the image endpoint treating directories whose names differ only by letter case as being inside the build folder. 7.4.6 fixed <code>astro check</code> exiting with code 0 despite errors, the <code>glob()</code> loader's file handling, an unnecessary page reload on first load, and i18n fallback for on-demand rendered pages. 7.4.5 covered background commands such as <code>astro dev status</code>, handling of <code>import.meta.env</code> values, and requests with invalid percent-encoded paths.</p>
<p><strong>What to check when upgrading</strong> — If you run <code>astro check</code> in CI, errors that used to pass may now fail, so run it once. Otherwise it is safe to upgrade as is.</p>
<p>Release notice: <a href="https://github.com/withastro/astro/blob/main/packages/astro/CHANGELOG.md">CHANGELOG</a></p>
<h4 id="pnpm-v12180--v112811">pnpm v12.18.0 · v11.28.11<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#pnpm-v12180--v112811"><span class="icon icon-link"></span></a></h4>
<p>A Node.js package manager.</p>
<p><strong>What changed</strong> — According to the change history, 12.18.0 centers on publishing and installing packages with per-platform variants. Variants uploaded from several machines can be published as one version, and a version made only of variants can be installed. <code>supportedArchitectures</code> is read as platform tags, and <code>pack --json</code> prints each archive's integrity value and size. A warning for undeclared required peer providers was added, and bugs in resolving relative <code>file:</code> peer paths, root overrides and catalog paths were fixed.</p>
<p><strong>What to check when upgrading</strong> — This summary comes from the change history only, so we could not confirm whether there are breaking changes. The 11.x line is a patch bump to 11.28.11; if you are moving to 12, check the official migration guide separately.</p>
<p>Release notice: None</p>

<p>A platform for building desktop apps with web technologies.</p>

In the docs, the Experimental label was dropped from the deprecated BrowserView APIs.</p>
<p><strong>What to check when upgrading</strong> — Because many Chromium patches are included, check rendering and PDF viewing after upgrading. We did not read any API change notice.</p>
<p>Release notice: None</p>

<p>A server-rendering React framework.</p>
<p><strong>What changed</strong> — 16.4.5 strips internal middleware cookie headers from edge responses and fixes stale compressed framing on forwarded fetch responses. <h4 id="nx-2405-3-patches">Nx 24.0.5 (3 patches)<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#nx-2405-3-patches"><span class="icon icon-link"></span></a></h4>
<p>A monorepo build system.</p>
<p><strong>What changed</strong> — 24.0.3 through 24.0.5 contain many hardening-style fixes.
