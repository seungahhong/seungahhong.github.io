f:Tdf55,<h2 id="canvas-api">Canvas API<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#canvas-api"><span class="icon icon-link"></span></a></h2>
<ul>
<li>The Canvas API provides a means for drawing graphics via <a href="https://developer.mozilla.org/ko/docs/Web/JavaScript">JavaScript</a> and the <a href="https://developer.mozilla.org/ko/docs/Web/HTML">HTML</a> <a href="https://developer.mozilla.org/ko/docs/Web/HTML/Element/canvas">CANVAS</a> element. Among other things, it is used for animation, game graphics, data visualization, photo manipulation, and real-time video processing.</li>
</ul>

<h2 id="libraries">Libraries<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#libraries"><span class="icon icon-link"></span></a></h2>
<ul>
<li><a href="https://www.createjs.com/easeljs">EaselJS</a> is an open-source canvas library that makes it easy to create games, generative art, and other highly graphical experiences.</li>
<li><a href="http://fabricjs.com/">Fabric.js</a> is an open-source canvas library with SVG parsing capabilities.</li>
<li><a href="https://www.patrick-wied.at/static/heatmapjs/">heatmap.js</a> is an open-source library for creating canvas-based data heatmaps.</li>
<li><a href="https://thejit.org/">JavaScript InfoVis Toolkit</a> creates interactive data visualizations.</li>
<li><a href="https://konvajs.github.io/">Konva.js</a> is a 2D canvas library for desktop and mobile applications.</li>
<li><a href="https://p5js.org/">p5.js</a> includes a full set of canvas drawing functionality for artists, designers, educators, and beginners.</li>
<li><a href="http://paperjs.org/">Paper.js</a> is an open-source vector graphics scripting framework that runs on top of the HTML5 Canvas.</li>
<li><a href="https://phaser.io/">Phaser</a> is a fast, free, and fun open-source framework for Canvas- and WebGL-based browser games.</li>
<li><a href="https://processingjs.org/">Processing.js</a> is a port of the Processing visualization language.</li>
<li><a href="https://ptsjs.org/">Pts.js</a> is a library for creative coding and visualization using canvas and SVG.</li>
<li><a href="https://github.com/jeremyckahn/rekapi">Rekapi</a> is an animation keyframe API for Canvas.</li>
<li><a href="https://scrawl.rikweb.org.uk/">Scrawl-canvas</a> is an open-source JavaScript library for creating and manipulating 2D canvas elements.</li>
<li><a href="https://zimjs.com/">ZIM</a> is a framework that provides conveniences, components, and controls for creative coding on canvas. It includes accessibility support and a wide range of tutorials.</li>
</ul>

<h3 id="drawing-rectangles">Drawing Rectangles<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#drawing-rectangles"><span class="icon icon-link"></span></a></h3>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/fillRect">fillRect(x, y, width, height) (en-US)</a></p>
<p>Draws a filled rectangle.</p>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/strokeRect">strokeRect(x, y, width, height) (en-US)</a></p>
<p>Draws a rectangular outline.</p>

<h3 id="drawing-paths">Drawing Paths<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#drawing-paths"><span class="icon icon-link"></span></a></h3>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/beginPath">beginPath() (en-US)</a></p>
<p>Creates a new path. Once a path is created, subsequent drawing commands are used to build and shape the path.</p>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/closePath">closePath() (en-US)</a></p>
<p>Adds a straight line connecting to the start of the current sub-path.</p>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/stroke">stroke() (en-US)</a></p>
<p>Draws a shape using its outline.</p>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/fill">fill() (en-US)</a></p>
<p>Fills the interior of the path, drawing a shape with its inside filled.</p>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/moveTo">moveTo() (en-US)</a></p>
<p>Moves to the new x, y coordinates.</p>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/lineTo">lineTo() (en-US)</a></p>
<p>Adds a line based on the coordinates you moved to.</p>
<p>Path methods (<a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D#paths">Path methods</a>)</p>
<p>These are functions used to set the various paths needed when constructing an object.</p>

<h2 id="drawing-text">Drawing Text<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#drawing-text"><span class="icon icon-link"></span></a></h2>

<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/font">font = value (en-US)</a></p>
<p>The current text style used when drawing text. This string uses the same syntax as the <a href="https://developer.mozilla.org/en-US/docs/Web/CSS">CSS</a> <a href="https://developer.mozilla.org/ko/docs/Web/CSS/font">font</a> property. The default is 10px sans-serif.</p>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/textAlign">textAlign = value (en-US)</a></p>
<p>Sets the text alignment. Available values: start, end, left, right, center. The default is start.</p>
<p><a href="https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/textBaseline">textBaseline = value (en-US)</a></p>
<p>Sets the baseline alignment. Available values: top, hanging, middle, alphabetic, ideographic, bottom. The default is alphabetic.</p>
<ul>
<li>Description
<ul>
<li>top: The baseline is placed at the top of the text.</li>
<li>middle: The baseline is placed at the middle of the text.</li>
<li>bottom: The baseline is placed at the bottom of the text.</li>
<li>alphabetic: Aligns to the baseline of the alphabet. This is the default.</li>
<li>hanging: Aligns to the top of the characters. Indic languages use this method.</li>
<li>ideographic: Used by square characters such as Chinese and Japanese. The baseline is positioned slightly lower than the alphabetic one.</li>
</ul>
</li>
</ul>
<p><a href="https://www.w3schools.com/tags/playcanvas.asp?filename=playcanvas_textbaseline&#x26;preval=hanging">Playit</a></p>

<h2 id="animation">Animation<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#animation"><span class="icon icon-link"></span></a></h2>
<p>Animation steps</p>
<ol>
<li>Clear the canvas (ctx.clearRect). Unless the shape you want to draw fills the entire canvas (as when creating a background image), you need to clear all previously drawn shapes. The easiest way is to use the clearRect() method.</li>
<li>Save the canvas state (ctx.save). If you are going to change settings that affect the canvas state (style changes, transformations, etc.) and use the changed values for each frame, you need to save the original state.</li>
<li>Draw the shapes to animate (ctx.fill, stroke~~). This is the step where the actual scene is drawn.</li>
<li>Restore the canvas state (ctx.restore). Restore the saved state before drawing a new scene.</li>
</ol>
<p>Calling a specific function at fixed intervals</p>
<ul>
<li>setInterval(function, delay)
<ul>
<li>Starts repeatedly executing the function every delay milliseconds (thousandths of a second).</li>
</ul>
</li>
<li>setTimeout(function, delay)
<ul>
<li>Executes the function after delay milliseconds (thousandths of a second) have elapsed.</li>
</ul>
</li>
<li>requestAnimationFrame(function)
<ul>
<li>Executes the function in sync with the display's refresh rate.</li>
</ul>
</li>
</ul>
