21:T7012,<h2 id="overview">Overview<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#overview"><span class="icon icon-link"></span></a></h2>
<p>This document describes how to register, install, and use the Claude Code plugin marketplace.</p>
<p>Plugins are shared through the <strong>seungah-claude-plugins</strong> marketplace. It currently consists of the following four team-specific plugins.</p>
<p>Marketplace version: <strong>1.4.0</strong> · Repository: <a href="https://github.com/seungahhong/seungah-claude-plugins">https://github.com/seungahhong/seungah-claude-plugins</a></p>






























<table><thead><tr><th>Plugin</th><th>Description</th><th>Version</th></tr></thead><tbody><tr><td>frontend-harness</td><td>A collection of multi-agent skills, commands, and hooks that support the entire frontend development process (Research → PRD → Develop → Review → Verify). Includes parallel execution of user-selected items among 5 static analysis perspectives (simplification, PR review, security, performance, consistency) plus a re-review loop, along with E2E and type/build verification</td><td>1.3.0</td></tr><tr><td>harness-generator</td><td>A meta-plugin that automatically generates a domain-agnostic harness (agent team + skills + orchestrator) through a 7-step meta process</td><td>0.1.0</td></tr><tr><td>git-harness</td><td>Git workflow — writing Korean commit messages (<code>issue-number type: subject</code>) and multi-perspective PR reviews (review → commit → PR, all in one)</td><td>0.2.0</td></tr><tr><td>meta-harness</td><td>Meta-harness engineering based on a full-trace experience store. Causal diagnosis + 4-axis Pareto non-regression patches, with a user approval gate (based on arXiv 2603.28052v1)</td><td>0.1.0</td></tr></tbody></table>

<h2 id="using-the-github-repository">Using the GitHub Repository<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#using-the-github-repository"><span class="icon icon-link"></span></a></h2>
<p>Repository: <a href="https://github.com/seungahhong/seungah-claude-plugins">https://github.com/seungahhong/seungah-claude-plugins</a></p>
<h3 id="how-users-use-it">How users use it<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#how-users-use-it"><span class="icon icon-link"></span></a></h3>
<ol>
<li><strong>Register the marketplace</strong> — In Claude Code, run <code>/plugin marketplace add https://github.com/seungahhong/seungah-claude-plugins</code> (or the CLI <code>claude plugin add seungahhong/seungah-claude-plugins</code>)</li>
<li><strong>Install plugins</strong> — Install only the plugins you want, such as <code>/plugin install frontend-harness@seungah-claude-plugins</code> (choose user / project / local scope)</li>
<li><strong>Run skills</strong> — After installation, invoke them via slash commands like <code>/planner</code>, <code>/review</code>, <code>/commit</code>, or trigger them with natural language. If the list does not appear, retry after running <code>/reload-plugins</code></li>
<li><strong>Update</strong> — When changes are reflected in the repository, update to the latest with <code>/plugin marketplace update seungah-claude-plugins</code></li>
</ol>
