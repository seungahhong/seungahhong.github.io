1a:Tcbb3,<h2 id="what-is-swr">What is SWR?<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#what-is-swr"><span class="icon icon-link"></span></a></h2>
<ul>
<li>A React Hooks library for remote data fetching, created by zeit, the group behind Next.js</li>
<li>SWR is a strategy that first returns the data from cache (stale), then sends the fetch request (revalidate), and finally arrives at the up-to-date data</li>
</ul>
<h2 id="swr-features">SWR Features<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#swr-features"><span class="icon icon-link"></span></a></h2>
<ul>
<li>Simplifies the data fetching logic in your project down to a single line of code</li>
<li><strong>Fast</strong>, <strong>lightweight</strong>, and <strong>reusable</strong> data fetching</li>
<li>Built-in <strong>cache</strong> and request deduplication</li>
<li><strong>Real-time</strong> experience</li>
<li>Transport and protocol agnostic</li>
<li>SSR / ISR / SSG support</li>
<li>TypeScript ready</li>
<li>React Native</li>
</ul>
<h2 id="swr-covers-every-aspect-of-speed-correctness-and-stability-so-you-can-build-a-better-experience">SWR covers every aspect of speed, correctness, and stability so you can build a better experience<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#swr-covers-every-aspect-of-speed-correctness-and-stability-so-you-can-build-a-better-experience"><span class="icon icon-link"></span></a></h2>
<ul>
<li>Fast page navigation</li>
<li>Interval polling</li>
<li>Data dependency</li>
<li>Revalidation on focus</li>
<li>Revalidation on network recovery</li>
<li>Local mutation (Optimistic UI)</li>
<li>Smart error retry</li>
<li>Pagination and scroll position recovery</li>
<li>React Suspense</li>
</ul>
