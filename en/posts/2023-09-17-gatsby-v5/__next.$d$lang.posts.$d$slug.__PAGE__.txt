<h4 id="slice-api">Slice API<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#slice-api"><span class="icon icon-link"></span></a></h4>
<p>Common components can now be built just once, which improves build performance.</p>
<p>In other words, when a component split out as a Slice changes, it is built only once and then merged into other parts of the site, so there is no need to rebuild everything as before.</p>

<h3 id="changes">Changes<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#changes"><span class="icon icon-link"></span></a></h3>
<h4 id="minimal-nodejs-version-1800">Minimal Node.js version 18.0.0<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#minimal-nodejs-version-1800"><span class="icon icon-link"></span></a></h4>
<p>As support for Node 14 and 16 is nearly discontinued, the minimum supported Node version is set to 18.</p>
<h4 id="minimal-required-react-version-is-18">Minimal required React version is 18<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#minimal-required-react-version-is-18"><span class="icon icon-link"></span></a></h4>
<p>React 18 or higher is now the minimum supported version; version 18 or above is required to support partial hydration.</p>
<h4 id="non-esm-browsers-are-not-polyfilled-by-default">Non-ESM browsers are not polyfilled by default<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#non-esm-browsers-are-not-polyfilled-by-default"><span class="icon icon-link"></span></a></h4>
<p>Polyfill support is discontinued for browsers that do not support ES6 modules (like Internet Explorer).</p>
<h4 id="graphql-schema-changes-to-sort-and-aggregation-fields">GraphQL schema: Changes to sort and aggregation fields<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#graphql-schema-changes-to-sort-and-aggregation-fields"><span class="icon icon-link"></span></a></h4>
