<h3 id="changes-by-package">Changes by package<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#changes-by-package"><span class="icon icon-link"></span></a></h3>
<h4 id="nodejs-v26121--v24221--v22234">Node.js v26.12.1 · v24.22.1 · v22.23.4<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#nodejs-v26121--v24221--v22234"><span class="icon icon-link"></span></a></h4>
<p>The runtime that executes JavaScript on servers.</p>
<p><strong>What changed</strong> — The Current line v26.12.1 and the LTS line v24.22.1 are security releases fixing 9 CVEs. The High-severity items make TLS reject non-canonical IP address forms and fix an IP normalization regression, validate null bytes in DNS resolve input, and fix Brotli-related issues; Medium covers the HTTP agent data guard and cache randomization reset between snapshots; Low covers the zlib ZIP header cache, fs permission wildcards and the <code>realpathSync</code> permission check. Root certificates moved to NSS 3.131.1, c-ares to 1.34.9, and TLS now rejects certificate chains containing blocked public keys. The maintenance line v22.23.4 received the same set of security fixes.</p>
<p><strong>What to check when upgrading</strong> — The notes list no breaking changes, but connections that were previously accepted may now be rejected (TLS, non-canonical IPs, certificate chains), so verify outbound connections after upgrading. These are security patches, so LTS users should upgrade soon.</p>
<p>Release notes: <a href="https://github.com/nodejs/node/releases/tag/v26.12.1">v26.12.1</a> · <a href="https://github.com/nodejs/node/releases/tag/v24.22.1">v24.22.1</a> · <a href="https://github.com/nodejs/node/releases/tag/v22.23.4">v22.23.4</a></p>
<h4 id="astro-742">astro 7.4.2<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#astro-742"><span class="icon icon-link"></span></a></h4>
<p>A JavaScript web framework.</p>
<p><strong>What changed</strong> — A patch release that raises the minimum supported Node.js to 22.23.4. With <code>experimental.collectionStorage: "chunked"</code>, content sync is much faster — from 60 seconds to under 1 second for about 44,000 entries. Fixes include a node-fetch error with the Cloudflare adapter and <code>astro dev</code>, a stale lock file that stopped unrelated processes, i18n types for <code>defaultLocale</code>, <code>fallback</code> and <code>domains</code>, a <code>server:defer</code> island error, and invalid JS generated from env values containing <code>$</code>.</p>
<p><strong>What to check when upgrading</strong> — Confirm Node.js is 22.23.4 or later. Otherwise it is safe to upgrade as is.</p>
<p>Release notes: <a href="https://github.com/withastro/astro/releases/tag/astro%407.4.2">astro@7.4.2</a></p>
<h4 id="zed-v1253--v1244">Zed v1.25.3 · v1.24.4<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#zed-v1253--v1244"><span class="icon icon-link"></span></a></h4>
<p>A fast code editor written in Rust.</p>
<p><strong>What changed</strong> — v1.25.2 shrank binaries by about 33% on macOS, 28% on Windows and 7% on Linux, added GPT-6 Astra, Claude Fable 5.1 and Claude Opus 5.5 models on Amazon Bedrock, external agent (ACP) session notifications and context compaction, double-click editing of inlay hints, and faster SSH connections. <p><strong>What changed</strong> — v0.40.11 supports speech generation on macOS through <code>ollama run</code> and the <code>/v1/audio/speech</code> endpoint, and adds the d3 decision model family (2B–27B). v0.40.10 added NVIDIA Nemotron 3.5 Bolt E4B (Gemma 4-based vision-language, 128K context), and v0.40.8 introduced Flint, an MoE coding model (40B total, about 2.5B active, 262K context), starting macOS-only. v0.40.9 extends Flint to Linux and Windows, reports streaming generation failures, and passes cloud model context settings to coding tools.</p>
