10:T28106,<h2 id="what-is-redux-toolkit">What is Redux Toolkit?<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#what-is-redux-toolkit"><span class="icon icon-link"></span></a></h2>
<ul>
<li>The Redux Toolkit library was created to address three concerns the Redux team had.</li>
</ul>
<ol>
<li>Configuring a Redux store is too complicated.</li>
<li>To make Redux useful, you have to install many additional packages.</li>
<li>Redux requires too much boilerplate code.</li>
</ol>
<p>The library that solves these three problems is Redux Toolkit, which makes Redux far easier and more convenient to use. Let's now look at how to use Redux Toolkit and how it solves the problems above.</p>
<h2 id="installation">Installation<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#installation"><span class="icon icon-link"></span></a></h2>
<pre><code>npm install @reduxjs/toolkit react-redux
</code></pre>
<h3 id="redux-toolkit-api">Redux Toolkit API<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#redux-toolkit-api"><span class="icon icon-link"></span></a></h3>
<ul>
<li>configureStore: A function similar to Redux's createStore function that provides simplified configuration options and sensible defaults. It automatically combines slice reducers, lets you add middleware, and includes redux-thunk by default. It also enables the use of the Redux DevTools Extension.</li>
<li>createReducer: Instead of writing a reducer function as a switch statement, it lets you use a lookup table approach for the reducer function, and it has the immer library built in so you can write mutative code.</li>
<li>createAction: Generates an action creator function from a given action type string. Since the function itself has toString() defined, it can be used in place of a constant type.</li>
<li>createSlice: Accepts a reducer function, a slice name, and an initial value, and automatically generates a slice reducer with its action creators and action types.</li>
<li>createAsyncThunk: A replacement for redux-thunk.</li>
<li>createSelector: Identical to the utility functionality of the reselect library.</li>
</ul>
<h3 id="advantages-of-redux-toolkit">Advantages of Redux Toolkit<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#advantages-of-redux-toolkit"><span class="icon icon-link"></span></a></h3>
<ul>
<li>You don't need to create action types or action creators separately.</li>
<li>immer is built in, so you can use mutable objects.</li>
<li>redux-thunk is built in, so asynchronous operations are supported.</li>
<li>TypeScript is supported.</li>
<li>reselect is built in.</li>
</ul>
