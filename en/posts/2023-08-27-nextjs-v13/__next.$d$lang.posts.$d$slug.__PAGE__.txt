<h2 id="summary">Summary<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#summary"><span class="icon icon-link"></span></a></h2>
<ul>
<li>Internet Explorer has been dropped from the list of supported browsers, and the set of <a href="https://nextjs.org/docs/basic-features/supported-browsers-features">modern browsers</a> is now supported instead.
<ul>
<li>Chrome 64+</li>
<li>Edge 79+</li>
<li>Firefox 67+</li>
<li>Opera 51+</li>
<li>Safari 12+</li>
</ul>
</li>
<li>The minimum Node version changed from 12.22.0 to 14.0.0.</li>
<li>The minimum React version also changed from 17.0.2 to 18.2.0.</li>
<li>The default value of swcMinify changed from false to true.</li>
<li>The new image component introduced in Next.js 12, next/future/image, became next/image, and next/image became next/legacy/image.
<ul>
<li>A <a href="https://nextjs.org/docs/advanced-features/codemods#next-image-to-legacy-image">codemod</a> is provided for automatic migration (next-image-to-legacy-image).</li>
</ul>
</li>
<li>Previously, using Next/Link required adding a nested <code>&#x3C;a></code> tag, but starting with version 13 the <code>&#x3C;a></code> link is no longer required.</li>
</ul>

<li>
<p>loading.js</p>
<ul>
<li>A file used to create loading UI for a specific part of the app (React Suspense Boundary).</li>
</ul>
</li>
<li>
<p>error.js</p>
<ul>
<li>An error component that is invoked when an error occurs in a subtree (React Suspense Boundary).</li>
</ul>
</li>
<li>
<p>template.js</p>
<ul>
<li>A file used when specific behavior is required.</li>
<li>Starting/ending animations using a CSS or animation library.</li>
<li>Features that rely on useEffect (e.g. logging page views) and useState (e.g. per-page feedback forms).</li>
<li>Changes the default framework behavior. For example, a Suspense boundary inside a layout shows the fallback only when the layout is first loaded, not when switching pages. With a template, the fallback is shown on each navigation.</li>
</ul>
</li>
<li>
<p>head.js</p>
<ul>
<li>Used to define the contents of the <code>&#x3C;head></code> tag.</li>
</ul>
</li>
<li>
<p>not-found.js</p>
<ul>
<li>Invoked when a page cannot be found.</li>
</ul>
