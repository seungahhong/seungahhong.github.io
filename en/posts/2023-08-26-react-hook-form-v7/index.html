react-hook-form v7

SSeungAh Hong·08/26/2023·2min read
  • form

Installation

react-hook-form v5 → v7 changes

useForm

Removed the validation prefix from config option names The errors object was moved to become a property of the formState object The default value of shouldUnregister was changed from false to true

validationSchema → resolver

Added an options object as the third argument to resolver

register

The register method is no longer assigned to a ref; instead it is spread onto the input props. return the following props: onChange, onBlur, name and ref.

Apply the codemod library

Changed the notation for accessing array-shaped objects from [] brackets to . separators. That said, code using bracket notation still works correctly.

Custom register Instead of passing a name attribute to register, just pass the name as the first argument.

valueAs now runs before the validate function is invoked

When destructuring register, you must call it before render and pass the values through

Controller

The API is simpler to use, and the previous props are now passed as props to the render method. The as prop was removed, and field and fieldState are now included in the render props.

  • field: onChange, onBlur, Value
  • fieldState: isDirty, dirtyFields rules no longer supports the valueAs* methods.

flat form option values(not support)

Returns a nested object by default

triggerValidation → trigger

The method name was changed to trigger The return value of trigger was changed to void

FormContext → FormProvider

The component name was changed to FormProvider

Dirty → isDirty

dirtyFields

Changed so that you access dirtyFields as an object property rather than calling it as a method

ErrorMessage

Split out from the error core library

clearError → clearErrors

setError

The logic for receiving properties was changed from arguments to an object The logic that accepted an array as an argument to setError was removed, so it now sets only a single error Added an options object as the third argument to setError

setValue

With setValue, the dirty field is now added by default, support for multiple errors was dropped, and the logic that accepted an array was removed

TypedController, useTypedController(not support)

TypedController → Controller useTypedController → useController

useFieldArray

Changed the property syntax for focus handling, added type generics, and cast the name to const during type checks (due to stricter type checking)

touched → touchedFields

watch

The return value of watch was changed from an object to an array

reset

The second argument was updated to allow more detailed configuration
