1b:Te9c7,<h2 id="purpose-of-adoption">Purpose of Adoption<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#purpose-of-adoption"><span class="icon icon-link"></span></a></h2>
<ul>
<li>As planning and design proceed in parallel and the spec keeps changing, the goal is to reflect those changes and share them with planners and designers.</li>
<li>When working in parallel with the backend as well, the logic (container) and the view (presentation) must be separated, so we develop components at the Storybook level to validate that separation.</li>
<li>Storybook is actively leveraged later when running screen-level tests.</li>
<li>Others
<ul>
<li>We also develop screen-level components while considering accessibility.</li>
</ul>
</li>
</ul>

<h2 id="applying-addon-knobs">Applying addon-knobs<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#applying-addon-knobs"><span class="icon icon-link"></span></a></h2>
<ul>
<li>@storybook/addon-knobs
<ul>
<li>An addon that helps you interact with various components.</li>
</ul>
</li>
<li>Types of Knobs controls
<ul>
<li>text: Lets you enter text.</li>
<li>boolean: Lets you set a true/false value with a checkbox.</li>
<li>number: Lets you enter a number. You can also set intervals such as 1–10.</li>
<li>color: Lets you set a color through a color palette.</li>
<li>object: Lets you set an object or array in JSON form.</li>
<li>select: Lets you choose one of several options through a select box.</li>
<li>radios: Lets you choose one of several options through radio buttons.</li>
<li>date: Lets you pick a date.
<img src="/blog-assets/2022/03/assets/19/Untitled.png" alt="Untitled"></li>
</ul>
</li>
</ul>
