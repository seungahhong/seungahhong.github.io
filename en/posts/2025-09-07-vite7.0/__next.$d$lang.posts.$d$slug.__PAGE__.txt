28:T5044,<h2 id="vite-70-release-key-changes-and-migration-guide">Vite 7.0 Release: Key Changes and Migration Guide<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#vite-70-release-key-changes-and-migration-guide"><span class="icon icon-link"></span></a></h2>
<p>On June 24, 2025, Vite 7.0 was officially released. This major version includes significant changes such as an updated Node.js support policy, revised browser targets, and Rolldown integration. Weekly downloads have reached 31 million, an increase of 14 million since the previous major release.</p>

<h3 id="key-changes">Key Changes<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#key-changes"><span class="icon icon-link"></span></a></h3>
<h4 id="1-higher-nodejs-support-requirements">1. Higher Node.js Support Requirements<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#1-higher-nodejs-support-requirements"><span class="icon icon-link"></span></a></h4>
<p>Vite 7.0 now requires <strong>Node.js 20.19+ or 22.12+</strong>.</p>
<p><strong>Reasons for the change:</strong></p>
<ul>
<li>A Node.js version that can use <code>require(esm)</code> without a flag is required</li>
<li>Vite can be distributed as ESM-only</li>
<li>Node.js 18 support has been dropped</li>
</ul>
<h4 id="2-browser-target-change">2. Browser Target Change<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#2-browser-target-change"><span class="icon icon-link"></span></a></h4>
<p>The default browser target has changed from <code>'modules'</code> to <code>'baseline-widely-available'</code>.</p>
<p><strong>Updated minimum browser versions:</strong></p>






























<table><thead><tr><th>Browser</th><th>Vite 6.0</th><th>Vite 7.0</th></tr></thead><tbody><tr><td>Chrome</td><td>87</td><td>107</td></tr><tr><td>Edge</td><td>88</td><td>107</td></tr><tr><td>Firefox</td><td>78</td><td>104</td></tr><tr><td>Safari</td><td>14.0</td><td>16.0</td></tr></tbody></table>
<p>This change makes it possible to leverage more modern JavaScript features, reducing bundle size and improving performance.</p>
<h4 id="3-environment-api-improvements">3. Environment API Improvements<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#3-environment-api-improvements"><span class="icon icon-link"></span></a></h4>
<p>The experimental Environment API introduced in Vite 6 has been retained, with new features added.</p>
<p><strong>Key additions:</strong></p>
<ul>
<li><code>buildApp</code> hook: a new hook for coordinating between plugins during environment builds</li>
<li>Better plugin compatibility and per-environment build control</li>
</ul>
<h3 id="comparison-with-vite-60">Comparison with Vite 6.0<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#comparison-with-vite-60"><span class="icon icon-link"></span></a></h3>
<h4 id="key-differences">Key Differences<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#key-differences"><span class="icon icon-link"></span></a></h4>



































<table><thead><tr><th>Feature</th><th>Vite 6.0</th><th>Vite 7.0</th></tr></thead><tbody><tr><td>Node.js minimum version</td><td>18.0+</td><td>20.19+ / 22.12+</td></tr><tr><td>Default browser target</td><td><code>'modules'</code></td><td><code>'baseline-widely-available'</code></td></tr><tr><td>Rolldown support</td><td>None</td><td>Experimental support</td></tr><tr><td>Sass Legacy API</td><td>Deprecated</td><td>Removed</td></tr><tr><td>ESM distribution</td><td>Partial</td><td>Full ESM-only</td></tr></tbody></table>
<h4 id="performance-improvements">Performance Improvements<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#performance-improvements"><span class="icon icon-link"></span></a></h4>
<ul>
<li>Rolldown integration is expected to shorten build times for large projects</li>
<li>More efficient bundling and optimization</li>
</ul>
