<h2 id="1-concepts-and-key-strengths-of-mobx">1. Concepts and key strengths of Mobx<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#1-concepts-and-key-strengths-of-mobx"><span class="icon icon-link"></span></a></h2>
<ul>
<li>
<p>Core concepts of Mobx</p>
<ul>
<li>observable state
<ul>
<li>This is data that is being observed as Observable State. In Mobx, this state is watched, and when a change occurs it is responsible for triggering computed values and render actions.</li>
</ul>
</li>
</ul>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="jsx" data-theme="github-light-high-contrast github-dark-high-contrast"><code data-language="jsx" data-theme="github-light-high-contrast github-dark-high-contrast" style="display: grid;"><span data-line=""><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492">import</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6"> { observable } </span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492">from</span><span style="--shiki-light:#032563;--shiki-dark:#ADDCFF"> 'mobx'</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">;</span></span>
<span data-line=""> </span>
<span data-line=""><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492">class</span><span style="--shiki-light:#702C00;--shiki-dark:#FFB757"> Todo</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6"> {</span></span>
<span data-line=""><span style="--shiki-light:#702C00;--shiki-dark:#FFB757">  id</span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492"> =</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6"> Math.</span><span style="--shiki-light:#622CBC;--shiki-dark:#DBB7FF">random</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">();</span></span>
<span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">  @observable </span><span style="--shiki-light:#702C00;--shiki-dark:#FFB757">title</span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492"> =</span><span style="--shiki-light:#032563;--shiki-dark:#ADDCFF"> ''</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">;</span></span>
<span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">  @observable </span><span style="--shiki-light:#702C00;--shiki-dark:#FFB757">finished</span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492"> =</span><span style="--shiki-light:#023B95;--shiki-dark:#91CBFF"> false</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">;</span></span>
<span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">}</span></span></code></pre></figure>
<ul>
<li>computed values
<ul>
<li>These are values that are computed (derived) from the existing state as it changes.</li>
<li>The value is only recomputed when the state changes, and the computed result is stored and reused.</li>
<li>If the internal state of a computed value has not changed, the previously computed cached value is reused as-is.</li>
</ul>
</li>
</ul>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="jsx" data-theme="github-light-high-contrast github-dark-high-contrast"><code data-language="jsx" data-theme="github-light-high-contrast github-dark-high-contrast" style="display: grid;"><span data-line=""><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492">class</span><span style="--shiki-light:#702C00;--shiki-dark:#FFB757"> TodoList</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6"> {</span></span>

<span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">  @computed </span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492">get</span><span style="--shiki-light:#622CBC;--shiki-dark:#DBB7FF"> unfinishedTodoCount</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">() {</span></span>

<span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">  }</span></span>
<span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">}</span></span></code></pre></figure>
<ul>
<li>reaction
<ul>
<li>A Reaction is similar to Computed Values, but instead of computing a value it produces other side effects such as console output, network requests, or updating the React component tree.</li>
<li>custom Reaction: you can use autorun, reaction, and when.</li>
</ul>
</li>
</ul>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="jsx" data-theme="github-light-high-contrast github-dark-high-contrast"><code data-language="jsx" data-theme="github-light-high-contrast github-dark-high-contrast" style="display: grid;"><span data-line=""><span style="--shiki-light:#622CBC;--shiki-dark:#DBB7FF">autorun</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">(() </span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492">=></span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6"> {</span></span>
<span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">  console.</span><span style="--shiki-light:#622CBC;--shiki-dark:#DBB7FF">log</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">(</span><span style="--shiki-light:#032563;--shiki-dark:#ADDCFF">'Tasks left: '</span><span style="--shiki-light:#A0111F;--shiki-dark:#FF9492"> +</span><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6"> todos.unfinishedTodoCount);</span></span>
<span data-line=""><span style="--shiki-light:#0E1116;--shiki-dark:#F0F3F6">});</span></span></code></pre></figure>
<ul>
<li>actions
<ul>
<li>This refers to anything that changes state. In Mobx, all state changes happen through user actions.</li>
<li>action.bound → a decorator used to bind <code>this</code> for class components.</li>
</ul>
</li>
</ul>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="jsx" data-theme="github-light-high-contrast github-dark-high-contrast"><code data-language="jsx" data-theme="github-light-high-contrast github-dark-high-contrast" style="display: grid;"><span data-line=""><span style="--shiki-light:#66707B;--shiki-dark:#BDC4CC">// state가 항상 action으로만 변경되게끔 설정하는 옵션이다.</span></span>

</li>
<li>
<p>Characteristics of Mobx</p>
<ul>
<li>It is not restricted to a single store.</li>
<li>It allows for cleaner code.
<ul>
<li>You can remove boilerplate code such as mapStateToProps and mapDispatchToProps that Redux requires for connecting state and dispatch (@inject).</li>
</ul>
</li>
<li>It has advantages in encapsulation and information hiding (object-oriented concepts).
<ul>
<li>State can only be changed through methods (Model), and it can be managed privately via get/set.</li>
<li>configure({enforceActions: 'observed'})</li>
</ul>
</li>
<li>There is no need to maintain state immutability.
<ul>
<li>Unnecessary operations for maintaining immutability in Redux, such as immer or spread operations, are eliminated.</li>
</ul>
</li>
<li>No middleware is needed for asynchronous function calls.
<ul>
<li>Middleware such as redux-thunk or redux-saga is not required.</li>
</ul>
</li>
<li>TypeScript
<ul>
<li>It is written in TypeScript, so it works without installing the @type packages.</li>
</ul>
</li>
<li>Debugging is difficult due to computed values (recomputed/derived) and reaction calls.
<ul>
<li>While these are clearly good features, as the development volume grows, debugging automatic calls becomes difficult.</li>
<li>Depending on the developer's skill, it seems to be a good feature when used well.</li>
</ul>
</li>
</ul>
</li>
