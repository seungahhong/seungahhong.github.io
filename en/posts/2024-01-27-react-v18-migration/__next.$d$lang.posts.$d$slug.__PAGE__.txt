<h4 id="defaultprops-no-longer-supported">defaultProps no longer supported<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#defaultprops-no-longer-supported"><span class="icon icon-link"></span></a></h4>
<p>Starting from version 18.3, defaultProps is deprecated. (A warning is shown.)</p>
<p>We are currently on version 18.2, so please be careful not to add defaultProps going forward.</p>

<h4 id="switching-to-the-react-helmet-async-library">Switching to the react-helmet-async library<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#switching-to-the-react-helmet-async-library"><span class="icon icon-link"></span></a></h4>
<p>Cause</p>
<ul>
<li>Starting from React 17, componentWillMount, componentWillReceiveProps, and componentWillUpdate are no longer supported, and to keep using them you need to migrate via the UNSAFE_ prefix. Because react-helmet was using methods that are not supported in version 17, warnings were raised.</li>
<li><a href="https://legacy.reactjs.org/blog/2018/03/27/update-on-async-rendering.html">Update on Async Rendering – React Blog</a></li>
</ul>
<p>Improvement</p>
<ul>
<li>Switched to a library called react-helmet-async</li>
<li><a href="https://www.npmjs.com/package/react-helmet-async">npm: react-helmet-async</a></li>
<li><a href="https://benborgers.com/posts/react-helmet-async">How to fix "componentWillMount has been renamed"</a></li>
</ul>
